## DR-1 【最重要】アグリハブは「広告費ゼロ・口コミ」でどうやって5万人に到達したか

■ ここから貼る

日本の農業記録アプリ「アグリハブ」が、宣伝広告費を使わずに登録者5万人規模へ成長した経緯を、時系列で分解してください。

【なぜ調べるか】
私は個人開発で農業の作業記録アプリを作っています。Web版は公開済み、iOS版を10月中旬に申請予定。有料は月額980円、2026年12月末までに月額課金30万円（約307件）が目標です。**営業活動はせず、マーケティング予算もほぼゼロ**。実働10週。現在の利用者は2名、ストアレビューは0件です。
アグリハブは「宣伝広告費を一切使わず、口コミで広がった」と公表しており、**私と条件がほぼ同じ唯一の先行事例**です。JA提携や農機メーカー提携で伸びた他社（アグリノート×井関農機、KSAS×クボタ）は予算と営業が前提で参考になりません。

【答えてほしいこと】
1. **成長の時系列**。いつ何人だったか。創業者のインタビュー・登壇資料・note・SNSの過去投稿から、人数が読める発言を全部拾って年表にしてください
2. **最初の100人・1,000人はどこから来たか**。ここが一番知りたいところです
3. **開発者自身が現役農家であること**を、集客にどう使ったか（自分の農場の実践の公開、当事者としての発信、農家コミュニティでの立ち位置など）
4. **最初の外部露出は何だったか**（受賞、メディア掲載、SNSでの拡散、知人の紹介、勉強会など）。それぞれの時期と、その前後で人数がどう動いたか
5. **JAアクセラレーター（AgVenture Lab）採択は何人の時点か**。採択が成長の原因なのか、成長した結果として採択されたのか、時系列から判定してください
6. ストアレビュー数・評価の推移。「農業日誌アプリのユーザーレビュー1位」を掲げた時期
7. 同様に、日本の農業アプリ「畑らく日記」（MCPC award 受賞が露出源とされる）についても、分かる範囲で同じ項目を

【出力形式】
- 年表（時期 / 登録者数 / その時期にやっていたこと / 出典URL）
- 「最初の1,000人の出所」についての結論と、その根拠になった発言の引用
- 2026年の今、個人開発者が**再現できる施策**と**再現できない施策**（当時と環境が違うもの）の仕分け
- そこから引いた、予算ゼロで10週以内に実行できる施策の推奨リスト（優先順つき）

【守ってほしいこと】
- 一次情報（本人の発言・公式発表・料金ページ・公的統計）の原文に到達してください。検索結果の要約だけで数字を書かないこと
- すべての数字に出典URLを付ける。到達できなかったものは「未取得」と明記し、推測で埋めないでください。空欄のほうが価値があります
- 登録者数・DL数・利用組織数・アクティブ数を混ぜないでください。どの単位の数字かを毎回明示すること
- 「口コミで広がった」という説明を鵜呑みにせず、**実際には何がきっかけだったか**を疑ってください。結論に反する証拠を1つ以上探し、見つからなければ「探したが見つからなかった」と書いてください

## DR-2 競合の無料プランの上限を、原文で確定する

■ ここから貼る

日本の農業記録アプリ各社の「無料プランでどこまでできて、どこから有料か」を、公式ページの原文から確定させてください。

【なぜ調べるか】
私は農業の作業記録アプリを個人開発しており、月額980円の有料プランを設計中です。ところが最大手のアグリハブのフリープランに「何人でも利用可能」「GAP管理」「病害虫診断」「帳票出力」などがすべて含まれるという情報があり、**無料で手に入るものに課金しようとしていないか**を確認する必要があります。競合の無料枠の上限が分からないと、有料の線をどこに引けばいいかが決まりません。

【調べてほしい対象】
アグリハブ / アグリノート / KSAS（クボタ） / 栽培アシストAI / 経営アシストAI / 畑らく日記 / レイミー（日本農薬） / Z-GIS（JA全農）。他に日本で使われている農業記録・営農管理アプリがあれば追加してください。

【各社について答えてほしいこと】
1. 無料プランでできることの**上限値**（圃場数、記録件数、ユーザー人数、分析できる期間、写真保存量など、数字で切られている箇所すべて）
2. 有料プランの**価格**（月額・年額）と、無料との具体的な差
3. **課金軸は何か**（機能で切るのか、規模で切るのか、データの保存・分析期間で切るのか、人数で切るのか）
4. **契約単位**（個人か、組織か、圃場数か、席数か）
5. **決済手段**（クレジットカードのみか、請求書払い・口座振替・コンビニ払いがあるか）
6. **個人農家が有料プランを契約できるか**。アグリハブは有料が事業者限定という情報があるので、規約の該当条文を確認してください
7. 無料トライアルの有無と期間
8. 過去2年の**値上げ・プラン改定の履歴**

【出力形式】
- 上記8項目 × 各社の一覧表。**全行に出典URL**
- 「980円/月で、競合の無料枠を超えて提供できるもの」の候補リスト
- 各社が**チーム利用（複数人）を無料にしているか有料にしているか**だけを抜き出した表（私は人数課金を検討しているため）

【守ってほしいこと】
- 料金ページ・利用規約の**原文**に到達してください。比較記事やまとめサイトの二次情報だけで書かないこと。二次情報しか取れなかった項目はそう明記してください
- すべての数字に出典URLと、可能なら確認日を付けてください
- 情報が古い可能性がある項目（過去の記事にしか無い数値など）は「◯年時点の値」と明記してください
- 「全部入っている」のような要約ではなく、**制限の数値そのもの**を取ってください

## DR-3 日本の農家は1世帯あたり何人が実働しているか

■ ここから貼る

日本の農業経営体について、1経営体あたり実際に農作業をしている人数の分布を、公的統計から取ってください。

【なぜ調べるか】
農業の作業記録アプリを作っており、**1人あたり月額980円**の課金を検討しています。1世帯が家族3人分を契約するなら、307席を集めるのに必要な契約数は約102件で済みますが、1世帯1人なら307件必要になります。**必要な獲得数が3倍変わる**ため、実際の人数分布を知る必要があります。

【答えてほしいこと】
1. **2025年農林業センサス**（および直近の農業構造動態調査）から、個人経営体の**農業従事者数の分布**。1人 / 2人 / 3〜4人 / 5人以上 が、それぞれ何経営体あるか
2. 同じく**常雇い**（年間7か月以上雇用）がいる経営体の数と、常雇い人数の規模別分布（1〜4人 / 5〜9人 / 10〜19人 / 20人以上）
3. **臨時雇い・季節雇用**の実態。年間延べ人数、雇用が発生する月の分布（繁忙期に集中するはず）
4. 法人経営体（約3.3万とされる）の、雇用規模の分布
5. 上記を踏まえた「1経営体あたり、**アプリのアカウントを持つ可能性がある人数**」の現実的な見込み
6. 参考: 農業者のスマートフォン所有率、営農アプリ利用率の公的推計があれば

【出力形式】
- 分布表（階級 / 経営体数 / 全体に占める割合）。**e-Stat の統計表番号と URL を明記**
- 「1経営体あたり平均◯人、中央値◯人」の結論
- 季節雇用の月別分布（**12月に人が動いている作目・地域が分かるなら特に知りたい**。農閑期に人数課金をすると席数が最少になるため）

【守ってほしいこと】
- e-Stat（政府統計の総合窓口）や農林水産省の公表資料の**原表**に到達してください。ニュース記事の引用値ではなく、統計表そのものから取ること
- 比率を出すときは**母数の定義を必ず書いてください**（「農業経営体」「個人経営体」「基幹的農業従事者」は別の数です。混ぜないこと）
- 到達できなかった項目は「未取得」と明記。推測で埋めないでください

## DR-4 予算ゼロで日本の農家に届く場所は、それぞれ何人いるか

■ ここから貼る

日本の農家が集まっているオンラインの場所を洗い出し、**それぞれの実際の人数**と、そこで自作アプリを紹介することが規約上許されるかを調べてください。

【なぜ調べるか】
農業の作業記録アプリを個人開発しており、**マーケティング予算がほぼゼロ**の状態で10週間でユーザーを集める必要があります。有料広告・展示会出展・新聞広告は予算的に不可能なので、**お金をかけずに露出できる場所**だけを知りたいです。推測ではなく、参加人数の実数が要ります。

【調べてほしいこと】
1. **X（旧Twitter）** の農家クラスタ。フォロワー1万人以上の農家アカウントは何件あり、合計リーチはどれくらいか。農業関連ハッシュタグの1日あたり投稿数
2. **Facebook の農業グループ**。グループ名・参加人数・**宣伝が規約で許されているか**（公開情報の範囲で）
3. **LINE オープンチャット / Discord** の農業関連の部屋と参加人数
4. **YouTube の農業チャンネル**。登録者1万人以上のチャンネル一覧と登録者数。タイアップの相場が公開されていれば
5. **note・ブログ** の農業ジャンルの読者規模
6. **農業系Webメディア**（マイナビ農業、AGRI JOURNAL、agri.mynavi、SMART AGRI 等）。**取材・記事化の持ち込み窓口**（広告ではなく編集部への情報提供の受け口）があるか、その連絡先
7. **無料または低額で使えるプレスリリース配信手段**と、農業メディアへ直接送る場合の送付先リスト
8. 農業関連の**オンラインコミュニティ・オンラインイベント**で、参加費・出展費が無料のもの
9. 参考までに、有料チャネル（農業WEEK出展、日本農業新聞広告）の**費用の実額**（今は使えないが、来年の判断材料として）

【出力形式】
- 場所ごとの一覧表: 名称 / 種別 / 参加人数または到達人数 / 宣伝の可否 / 連絡先やURL / 出典
- そのうち「**費用ゼロで、10週以内に1回以上露出できる**」ものだけを抜いたリスト
- 合計到達可能人数の見積もりと、その計算過程（想定クリック率・想定インストール率を明示して）

【守ってほしいこと】
- 人数は**公開されている実数**を取ってください。「多い」「活発」のような形容では使えません
- 規約で宣伝が禁止されている場所は、その旨を明記してください（知らずに投稿すると出禁になります）
- 到達できなかった数字は「未取得」と書いてください。推測で埋めないこと
- 「農家向け」と称していても実際の利用者が農業資材メーカーや流通業者である場合があります。**実際に誰がいる場所なのか**を確認してください

## DR-5 App Store / Google Play で農業記録アプリはどう探されているか（ASO）

■ ここから貼る

日本の App Store / Google Play で、農業の記録アプリがどんな言葉で探されていて、競合がどう最適化しているかを調べてください。

【なぜ調べるか】
農業の作業記録アプリを10月中旬に App Store へ申請予定です。**マーケ予算がゼロ**なので、ストア検索からの自然流入が最大の獲得手段になります。アプリ名・サブタイトル・キーワード・スクリーンショットの文言は**申請前に確定**させる必要があります（申請後の変更には審査が挟まるため）。

【答えてほしいこと】
1. 日本語で農業記録アプリを探すときに使われるキーワード（「農業日誌」「農作業記録」「農薬 記録」「防除記録」「営農管理」「圃場管理」「農業 アプリ」など）の**検索需要**。分かる範囲で構いません
2. 主要キーワードでの**競合アプリの順位**と、上位アプリの**アプリ名・サブタイトルの作り方**（どの語を入れているか）
3. 競合各社（アグリハブ、アグリノート、畑らく日記、KSAS、レイミー等）の**レビュー数と平均評価の現在値**（iOS / Android 両方）
4. 競合の**低評価レビュー（★1〜2）の内容**。何が理由で星を落としているか、多い順に。→ これは私がリリース前に潰すべき項目であり、同時に差別化の訴求ポイントになります
5. 競合の**高評価レビュー**で繰り返し褒められている点
6. 日本のアプリストアにおける、**評価とダウンロード率の関係**を示すデータ（★2→★4で何倍になるか等）
7. 農業に限らず、**ニッチなB2B向けアプリが ASO だけでどれくらいの流入を得られるか**の実例があれば

【出力形式】
- キーワード × 競合順位の表
- 競合のアプリ名・サブタイトルの一覧（実際の文字列そのまま）
- 低評価理由のランキング（引用つき）
- 上記を踏まえた**アプリ名・サブタイトル・キーワードの案**を3パターン。それぞれ、どのキーワードを狙っているかの説明つき
- スクリーンショット1枚目に載せるべき訴求文の案

【守ってほしいこと】
- レビュー数・評価は**確認日を明記**してください（変動するため）
- 検索ボリュームは推計値であることが多いので、**推計なのか実測なのか**を区別して書いてください
- 低評価レビューは**実際の文面を引用**してください。要約だけだと潰すべき項目が分かりません
- ストアのページに到達できなかった場合は、その旨を明記してください

## DR-6 個人開発者が日本で月額課金を始めるのに必要な手続きと、その所要期間

■ ここから貼る

日本の個人開発者（個人事業主）が、iOS アプリと Web で月額サブスクリプションの課金を開始するために必要な手続きと、それぞれの所要期間を調べてください。

【なぜ調べるか】
農業の作業記録アプリを個人で開発しており、月額980円の課金を始めたいです。**12月末までに実際に課金が立っている**必要があり、課金開始日がスケジュールの制約になっています。今どこから手をつければ12月に間に合うかを知りたいです。

【答えてほしいこと】
1. **App 内課金（自動更新サブスクリプション）**
   - Apple Developer Program の登録から、個人名義で課金を有効にするまでの手順と所要期間
   - 自動更新サブスクリプションの審査で落ちやすい要件（App Store Review Guidelines 3.1.1 / 3.1.2 で実際に指摘される点）
   - **App Store Small Business Program（手数料15%）の申請時期と、適用が始まるタイミング**（申請してすぐ適用されるのか、翌月以降か）
   - Apple からの**入金サイクル**（売上計上から着金までのずれ）
   - 有料アプリ契約に必要な銀行口座・税務情報（W-8BEN 等）の登録に要する期間
2. **Web での決済（Stripe 等）**
   - 個人事業主が Stripe のアカウントを開設するのに必要な書類と審査期間
   - サブスクリプション課金を始めるまでの最短日数
3. **特定商取引法に基づく表記**
   - 個人事業主の場合、**氏名・住所・電話番号の公開義務**の範囲
   - 「請求があったら遅滞なく開示する」という運用が認められる条件（経済産業省・消費者庁の見解）
   - App 内課金のみの場合と、Web 決済もある場合で違いがあるか
4. **インボイス制度**
   - 個人や法人の顧客に月額課金を売る場合、適格請求書発行事業者の登録が必要になるのはどんなときか
   - 登録申請から登録番号が出るまでの期間
5. **消費税**
   - 免税事業者（課税売上1,000万円以下）が月額980円を売る場合、980円は税込・税抜どちらとして扱うのが一般的か
6. **請求書払い・口座振替**
   - 法人顧客に請求書で売る場合の**標準的な支払サイト**（月末締め翌月末払いなど）
   - 口座振替を導入する場合の、金融機関への登録から引き落とし開始までのリードタイム
7. サブスクリプションの**クレジットカード決済の失敗率**と、**初月解約率**の一般的な水準

【出力形式】
- 手続きごとに: 何を / どこに / 何日かかるか / 費用 / 個人事業主でも可能か
- **「今日から始めた場合、最短で課金を開始できる日」**を、iOS経路と Web経路それぞれで
- 12月中に入金まで到達させるための**逆算スケジュール**

【守ってほしいこと】
