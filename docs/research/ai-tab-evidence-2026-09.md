# 調査: AIチャットを主要導線に置いたアプリはどうなったか

- 日付: 2026-09-09
- 問い: farm-app が「相談タブ」をボトムナビに置いた判断は妥当か
- 関連: [`docs/decisions/20260909-single-ai-entry-threads.md`](../decisions/20260909-single-ai-entry-threads.md)、[`docs/research/dl-target-20k-2026-09.md`](dl-target-20k-2026-09.md)

## 根拠の強さ（先に）

**原文に到達できたページはゼロ。** 作業環境の egress が日本語圏だけでなく apps.apple.com / play.google.com / techcrunch / wikipedia / statista / reddit まで遮断していた。以下はすべて**検索要約経由・原文未検証**で、`「」` はレビューの逐語引用ではない。

**星評価とレビュー件数は、ほぼ全滅した。** 両方が揃ったのは Cal AI（4.8★／66,000件）1件だけで、それは**会話UIを持たないカメラ単機能アプリ**。しかも 2026-04 に「欺瞞的な課金設計とアプリ内課金違反」で一時 App Store から削除されている。**「AIを前面に出したアプリは評価が高いのか」という問いには答えられていない。**

## 1. 最重要: Amazon Rufus はボトムナビのAIチャットタブを13か月でやめた

| 置いていた時期の実績 | 数値 |
|---|---|
| 2025年に利用した顧客 | **3億人** |
| MAU 成長 | **前年比 +149%** |
| インタラクション | +210% |
| 付随売上 | **年換算 約120億ドル** |
| 購入完了率 | 利用者は **60%高い** |

配置は**ボトムナビゲーションバー**、アイコンは**吹き出し＋きらめき**。

**そして 2026-05-13、Amazon は Rufus ブランドを終了し「Alexa for Shopping」として検索バーに埋め込んだ。**

理由（**二次ブログ経由・Amazonの一次表明としては未検証**）:

> 別のチャットインターフェースを開く摩擦が、デイリーアクティブのエンゲージメントを削いだ。AIは「行かなければならない目的地」ではなく、環境に溶けた（ambient）埋め込み型であるべき。

**規模の証明と、形の否定が同時に起きている。** 3億人が使い120億ドルを生んでも、独立タブという形は残らなかった。

## 2. 国内でボトムナビにAI/相談タブを置いた例は1件も確認できなかった

探した対象: Yahoo! JAPAN / LINE / PayPay / 楽天 / メルカリ / ママリ / ココナラ / 弁護士ドットコム / ルナルナ / あすけん / みんチャレ。（**不在の証明ではなく、取得できなかった**）

観測できた形はすべて**タブではない**。

| 事業者 | 形 |
|---|---|
| LINEヤフー「Agent i」 | 「LINEの各タブや Yahoo! JAPAN から**シームレスにアクセス**」＝タブ**から**入る |

| 弁護士ドットコム | 独立したαサービス（アプリ内タブではない） |

## 3. 構造が最も近いあすけんは、相談チャットを主要導線に置いていない

2026-06-15 に「AIこんだて提案（β版）」＝**未来さんに次の一食を相談できるチャット**を出したが、提供条件が絞られている。

- **β版／iOS先行／プレミアム加入者のみ／月10回まで**

会員900万〜1400万人規模（**2つの数字が出て食い違う。判断の根拠に使わない**）で、記録アプリのAI相談チャットを**いちばん絞った形で出している**。

一方、**主要導線に置いているのは入力系AI**。「AIおまかせ記録」は記録ホーム右下の「＋」と各食事記録画面の右下の**2か所に常設**。2025-09-30 には「**話して記録**」（AI語を出さない命名）を提供開始。

**同じ課題（面倒な記録を毎日続けさせる）に対する、規模のある事業者の答えは「入力に張る／相談は絞る」。**

## 4. 炎上した2件の共通点は「精度」ではなく「消せない一等地の占有」

| 事例 | 数値 |
|---|---|
| **Snapchat My AI**（2023-04、Chatフィード最上部にピン留め） | 平均評価 **3.05 → 1.67**、1★比率 **35% → 75%**、レビュー数 前週比5倍、"AI" が最頻出キーワードで2,973回 |
| **WhatsApp Meta AI**（2025-04、チャット一覧右下の**消せない**青い円） | 「pointless and irritating」「bug-ridden rubbish」、Signal 移行検討の声、削除オプション未提供、欧州議員がEU規則との整合性を照会 |

**どちらも不満の主因は AI の質ではなく配置。**

## 5. 汎用LLMとの比較負け・コスト

- あすけんのプレミアム解約者:「**Gemini の AI 画像解析の方が正確だった**」
- あすけんは 2026-06-17 に**プレミアム値上げを発表**（2026-08-18 適用）。理由に「**AI・画像解析処理のコスト増**」を明記

**主要導線に置く＝呼び出し回数最大化＝コスト最大化であり、同時に比較負けの露出も最大化する。**

## 6. AI機能が効いた／効かなかった数値

| 事例 | 数値 | 何を示すか |
|---|---|---|
| Duolingo「Explain My Answer」 | **65%が利用・コース修了率 +15%** | **効いた**。ただし独立タブではなく**間違えた直後の画面**に置かれた出力系AI |
| Duolingo Max（AI会話） | 総サブスクの5%→9%→**180万人**（$29.99/月） | 課金は伸びた。同時に**GenAIコストで粗利率が低下** |
| Amazon Rufus | 3億人／+149%／$120億 | 規模は出たが**形は廃止** |
| Snapchat My AI | 3.05 → 1.67 | 評価に効いた（悪い方向に） |
| あすけん AIこんだて提案β | 74%「負担が減った」／77%「栄養改善を実感」 | ポジティブ。ただし**社内アンケート**で継続率ではない |
| みんチャレ | 習慣化達成率 8倍 | **AIの効果ではなく「5人のチーム」の効果** |

**褒められている軸に共通するのは「相談が楽しい」ではなく「負担が減った／準備ができた」という成果。会話体験そのものを褒めるレビューは1件も拾えなかった。**

## 7. 反対側の材料（相談スレッドを残すべき理由）

- 自前の競合レビュー実測89件の結論は「**5★を分けるのは記録の出口があるか**」。従来 `ai_outputs` に落ちるだけで読み返せなかったものが、スレッドで初めて読み返せる＝**出口の追加**
- 89件中唯一の年齢言及（アグリハブ1★・20代新規就農）が求めたのは「種まきした日を入れると**今後の作業なども教えてくれる**」もの。ただしこれは「相談しに行く」ではなく「**勝手に出てくる**」形の要求
