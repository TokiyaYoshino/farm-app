- 関連: [`dl-target-20k-2026-09.md`](dl-target-20k-2026-09.md)、[`competitor-app-reviews-2026-08.md`](competitor-app-reviews-2026-08.md)、[`ai-placement-jp-apps-2026-09.md`](ai-placement-jp-apps-2026-09.md)

## 0. まず訂正 — 名称の調査は、これまで一度もしていない

**`dl-target-20k-2026-09.md` は名称を1行も扱っていない。** あの調査の対象は
流入経路（JA・農機メーカー・農薬メーカー）と★評価で、結論も
「律速は外の獲得経路であってアプリの中の作りではない」だった。

名称に触れている既存調査は `ai-placement-jp-apps-2026-09.md` の 8.2 だけだが、
あれは**機能名に「AI」を出すか**（25件中18件が出している）の話で、
**アプリ名の話ではない**。

本書はそのために新しく取った。

### 根拠の強さ

検索エンジン経由で取得。**ストアページの原文には到達できていない**（前回と同じ
egress の制約）。以下のうち「実際のストア名」は検索結果のタイトルに原文が現れたもので、
それ以外は要約経由。**商標と名称の一意性は、申請前に必ず自分でストアと
特許情報プラットフォーム（J-PlatPat）で確認すること。**

## 1. 仕組みとして効くこと（数字）

| 事実 | 出典 |
|---|---|
| App Store のタイトルは**30文字**まで（Google Play は50文字） | apptamin / appradar |
| **検索結果では18文字で切られる。** 最初の18文字が勝負 | appfollow |
| タイトルは**最も重み付けの大きいランキング要素**で、他フィールドの**2〜3倍**効く | appfollow |
| タイトル内のキーワードは、他の欄に置いたものより**速くインデックスされ、上位に来る** | appfollow |
| ただし**キーワードの詰め込みは転換率を下げる**（品質が低く見える） | apptweak |
| 上位アプリ（ゲーム以外）の多くは**タイトルにキーワードを入れ、かつ短い** | asoworld |
| **名前はストア全体で一意。** 同じ名前は登録できない（自分の別アプリとも） | 4.1 / 4.3 関連 |
| 4.1 は**他社のブランド・名前・アイコンの流用**を弾く。4.3 は**既にあるものと区別がつかないアプリ**を弾く | ptkd / 各ガイド |

**要約すると、勝ち筋は1つ。** 「覚えられる固有名」＋「実際に検索される語」を
**18文字以内**に収める。固有名だけだと検索で当たらず、キーワードだけだと
一意にできず転換率も落ちる。

## 2. 日本の農業アプリが実際に使っているストア名

検索結果のタイトルに原文が現れたものだけを並べる。

|---|---|---|
| **アグリノート – 農業日誌・圃場管理アプリ** | アグリノート | 農業日誌・圃場管理 |
| **KSAS（クボタスマートアグリシステム）** | KSAS | （社名＋説明） |

## 5. 推奨する型

```
<固有名 2〜5文字・漢字かひらがな> ＋ 全角ダッシュ ＋ <キーワード2語>   ／ 合計18文字以内
```

18文字に収めるのは、検索結果で切られないため。30文字の枠は残るので、
足したい語はサブタイトル（30文字）とキーワード欄（100文字）に回す。

### 候補（決めるのはオーナー。ここは叩き台）

| 候補 | 全体 | 字数 | 評 |
|---|---|---|---|
| **農録（のうろく）** | 農録 – 農作業記録と農薬管理 | 14 | 漢字2文字で短い。既存と衝突しない。**読みの説明が要る**のが弱点 |
| **みのり** | みのり – 農作業記録・農薬管理 | 15 | 読める・優しい・高齢層向き。**一般語なので商標が弱く、他業種に同名が多い** |
| **畑ろく** | 畑ろく – 農薬管理と作業記録 | 14 | 「畑」で農業と分かる＋「ろく（録）」。畑らく日記と音が近いのが気になる |

**キーワード部の最終選定には、ストアの検索ボリュームが要る。**
この環境からストアに到達できないため本書では決めない。

## 6. 決める前に必ず確認すること

1. **App Store / Google Play で同名が無いか**（名前はストア全体で一意）
2. **J-PlatPat で商標**（第9類・第42類あたり）。既存商標と紛らわしいと 4.1 で落ちる
3. **ドメイン**（`kishufarm.com` は保有済み。アプリ名と別でも運用はできる）
4. **`app.json` の `name` と bundle ID は別物。** bundle ID（`com.kishufarm.farmreport`）は
   **一度登録すると変更できない**が、**まだ登録していないので今なら変えられる**
   （`docs/app-store-submission.md` 2章）。名前を変えるならここも同時に決める

## 7. 追記（2026-09-22）:「農AI」「農業AI」の判定

### バッティング

**「農AI」という名前のアプリは検索に出てこなかった。**（不在証明ではない。ストアで要確認）

ただし**AI を名乗る農業アプリは既に密集している**。

| 名前 | 提供 | 中身 |
|---|---|---|
| レイミー | 日本農薬 | AI病害虫雑草診断 |
| SCIBAI（サイバイ） | — | 写真から病害虫を自動診断・11作物 |
| Agri-AR | 株式会社Root | AR農作業補助 |
| アグリショットScan | — | 画像診断系 |
| AI栽培レポート | Agrihub の機能 | 栽培レポート生成 |
| 栽培アシストAI / 経営アシストAI | — | `docs/roadmap.md` の価格比較で既出 |

**「◯◯AI」という形はこのカテゴリで既に定型句になっている。** 衝突はしないが、埋もれる。

### 勧めない理由は、バッティングより手前に3つある

**1. リポジトリの自分の決定と正面衝突する。**
`CLAUDE.md`:「**入口（ボタン・見出し）に「AI」の語を出さない。動作か成果で書く**」。
アプリ名は最大の入口。そして `20260823-ai-wording-outcome-based.md` が
AI語を落とした理由は「**汎用生成AI（ChatGPT等）が実質的な競合であり
「AIが使える」こと自体に課金価値が無い**」だった。
**名前で AI を名乗ると、その競合と同じ土俵に自分から立つ**ことになる。
「それ ChatGPT でよくない？」に名前の時点で答えられなくなる。

**2. 自分の調査が、揺り戻しを記録している。**
`ai-placement-jp-apps-2026-09.md` 8.2:
- Yahoo!ニュース「コメントAI要約（β版）」→ 正式版「**ヤフコメまとめ**」で**AI語が消えた**
- あすけん: 「AIおまかせ記録」と併存で「**話して記録**」を出した

機能名なら後から変えられるが、**アプリ名は変えにくい**。揺り戻しの方向に賭けることになる。

**3. 識別性が低い＝商標として守れない。**
「農AI」は記述的で、誰でも使える。4.1 で弾かれるとまでは言えないが、
**ブランドとして守れない**（第5章の「みのり」と同じ弱点が、より強く出る）。

### 折衷案

AI で検索されたいのであれば、**タイトル本体ではなくキーワード欄（100文字）とサブタイトル（30文字）に入れる**。

```
タイトル    : <固有名> – 農作業記録と農薬管理      ← AI語を入れない
サブタイトル : 写真で診断、記録から相談              ← 成果で書く（CLAUDE.md 準拠）
キーワード欄 : 農業AI,AI,病害虫,診断,農薬,防除,日誌...  ← ここで検索を拾う
```

タイトルよりは弱いが、**規約とも過去の決定とも衝突しない**。

## 8. 調査中に見つけた新しい競合（名前とは別件・重要）

**「ミノリス日誌」**（株式会社トクイテン・**2026年リリース**・初期費用も月額も無料）。
**ClaudeやChatGPTといった生成AIとの連携に対応し、ふだん使っているAIとの会話から
記録を確認できる**とされる（検索要約経由・**一次確認が必要**）。

**これは farm-app の唯一の差別化と正面から重なる。**
`docs/roadmap.md` が差別化の中核としているのは
「**記録する場所とAIに聞く場所が同一プロダクト内にある**」の一点だった
（2026-08 の競合調査で、そこだけが残ったと結論している）。
ミノリス日誌は**その逆側から**——記録を外部の生成AIに開いて——同じ用事を満たしにきている。

**名前の決定とは別に、料金プランの保留（`20260823-pricing-plan-review.md`）と
差別化軸の再確認が要る。** 本書では判定しない。一次情報の確認が先。

**あわせて第5章の候補「みのり」は取り下げる。**「ミノリス」と近く、
先行するサービスと紛らわしい（4.1 のリスクもある）。

## 9. 追記（2026-09-22）:「AI農（アイノウ）」の判定 — **2つとも当たる**

発案の意図は「簡易AIエージェント × 農業」＋「I know（私は知っている）」のダブルミーニング。
**発想は良い**（後述）。ただし**アイノウという音と綴りは、農業分野で二重に埋まっている。**

### 当たり① aKnow（エイノウ）— 同じダジャレ・1母音違い・同じカテゴリ

**App Store: 「aKnow(エイノウ) - 農作業や農薬を農業日誌で記録管理」**（AsuLab Inc. / `jp.asulab.aknow`）

| 項目 | 実測 |
|---|---|
| 機能 | 農作業記録／**農薬の使用回数と有効成分の集計**／JGAP対応／地図で圃場管理／農業日誌／原価・在庫・売上 |
| 評価 | 3.0★ / 7件（規模は小さい） |
| 名前の由来 | **a + Know = エイノウ = 営農** |

**問題は規模ではなく名前の構造。**
`AI農 = アイノウ = I know` は、`aKnow = エイノウ = 営農` と
**まったく同じ言葉遊びを、1母音ずらしただけ**になる。しかも**同じカテゴリ**で、
機能表もほぼ重なる（aKnow は**有効成分ベースの集計まで持っている**——farm-app が
データが無いため判定不可に倒した箇所・`20260823-pest-advice-history.md`）。

Guideline 4.1 は「**他社のアプリの名前に少し手を加えて自分のものとして出すな**」を
名指しで弾く。**拒否されなくても、利用者が取り違える。**

### 当たり② 愛農（アイノウ）— 農業分野で80年使われている

| 主体 | 年 |
|---|---|
| **公益社団法人 全国愛農会**（`ainou.or.jp`・有機農業教育・有機認証） | **1945年〜** |
| **愛農学園農業高等学校**（日本唯一の私立農業高校） | 1963年 |
| 株式会社愛農流通センター（農水省サイトに掲載） | 1982年 |

**ASO と SNS の観点では、これが致命的。**
「アイノウ」で検索すると社団法人と農業高校が出る。`#愛農` も既に使われている。
**認知拡大に予算と時間を使うほど、80年もののブランドに流入を渡すことになる。**
名前で拘りたいという動機と、いちばん相性が悪い形。

## 10. 発想は残す — 「知っている」を別の音で持つ

**元の発想の芯は正しい。** 「私は知っている」＝**あなたの記録を知っている**は、
`docs/roadmap.md` が差別化の中核としている
「記録する場所とAIに聞く場所が同一プロダクト内にある」そのもので、
名前と製品が一致する。捨てる必要はない。**衝突する音を替えるだけでよい。**

### 候補A: **知農（ちのう）** ←推奨

| 観点 | 評 |
|---|---|
| ダブルミーニング | **知農＝知能。** AI の語を出さずに AI を示す。`CLAUDE.md`「入口に『AI』の語を出さない」と衝突しない |
| 元の発想 | 「農を知っている」＝そのまま保持 |
| 規約 | 漢字2文字＝`CLAUDE.md`「カタカナ語より漢字語を優先（高齢層）」に合致 |
| 衝突 | 検索した範囲で**農業アプリ・サービスに見当たらず**（要ストア確認） |
| 型 | 「アグリ」「ノート」「ハブ」「日記」のいずれにも当たらない |
| **弱点** | **音で聞くと「知能」と区別がつかない。**（狙いでもあるが、口頭で伝えにくい）。愛農と違い競合する**農業ブランド**ではないので、被害は軽い |

**タイトル案: 「知農 – 農作業記録と農薬管理」（13文字／18文字の枠内）**

### 候補B: **きく農（きくのう）**

「**聞く**（相談する）」＋「**効く**（役に立つ）」のダブルミーニング。
farm-app の主操作が相談であることと合う。ひらがな混じりで読み違えない。
弱点は「菊（きく）」との混同と、漢字語優先の規約からやや外れること。

### そして farm-app 側の実測

- **本番の AI 呼び出しは開発時の確認のみ。** worker 0人・記録18件（`handoff-input-redesign.md` 2章）

### ただし、本当に持っている差はある（「賢さ」ではなく「設計」）

確認できた範囲で、上のどれも同時には持っていない組み合わせ。

1. **記録する場所と相談する場所が同一プロダクト内**
   （レイミーは診断専用／Agrihub のレポートは自動生成の一方通行で会話ではない／ミノリスは外部AIに開く形）
2. **コードが数えた集計をLLMに渡す。** 画面と AI が同じ `pesticideUsage.ts` を通るので**数字が食い違わない**
3. **FAMIC 原文を渡し、数値化できないものは判定不可に倒す。**「あと◯回使える」は明文で禁止
   （`20260908-advice-handoff.md`）＝**間違える方向に倒さない**
4. **相談が会話として続き**（`advice_threads`）、**助言と作業記録を照合する**（`adviceMatch.ts`）

**これは「AIが賢い」ではなく「AIに渡す材料と、間違えない設計」の差。**
モデルの進歩で消えないぶん、実は守りやすい。

### 名前への含意

- **「AIが優れている」を名前で主張すると、レイミー（農水省事例・農薬メーカー）や
  Agrihub（4万人）と正面比較され、いまは負ける。** ChatGPT と比べられれば
  `20260823-ai-wording-outcome-based.md` が指摘した「それ ChatGPT でよくない？」に戻る
- **勝てる主張は「あなたの記録を知っている AI」。** 汎用AIにもレイミーにもできない
  （**記録を持っていない**から）。元の「I know」の発想は、こちらの意味でなら正しい

## 13. 「AIエージェントとわかる」と両立させる形

オーナーの方針は「**AIエージェントだと分かることを優先したい**」。
名前の**固有名部分**で AI を名乗ると 12章の正面比較に入るが、
**キーワード部で名乗るなら、衝突も比較も避けつつ明示できる。**

```
タイトル    : 知農 – 農業AIエージェント        （13文字／18文字の枠内）
サブタイトル : あなたの記録を知っているAI        （勝てる主張・30文字枠）
キーワード欄 : 農業AI,AIエージェント,農薬,使用回数,病害虫,防除,農業日誌,栽培記録
```

- **「AIエージェント」はタイトル内に入るので、ASO の重み（他フィールドの2〜3倍）を受け取れる**
- 固有名は衝突しないものを使うので、4.1（aKnow）も愛農も踏まない
- 「AI」は**一般名詞として**使うので、誰かのブランドの流用にならない

### ただし決定が1つ要る

`CLAUDE.md`「**入口（ボタン・見出し）に「AI」の語を出さない**」との関係を決める必要がある。
**ストア名は「入口」ではなく「発見面」**——まだアプリを持っていない人に用途を伝える場所で、
既に使っている人に機能を指す UI 文言とは役割が違う。
**この線引きを決定ログに残せば、規約を破らずに両立できる。**（本書では決めない）

### キャラクター名という別解（国内で最も強い型）

`ai-placement-jp-apps-2026-09.md` 8.3 の観測：
**国内で AI をエージェントとして感じさせる最も強い手はキャラクターへの委譲**
（あすけん＝未来さん／SmartNews＝マーキュリーさん／みんチャレ＝にゃんチャレAI）。
「AI」の3文字より「**誰かに聞いている**」感じが出る。名前をエージェントの名前にする案は、
「AIエージェントとわかる」という要求に対して、**文字で名乗るより強く効く可能性がある。**
