### 「4軒に1軒」は真に受けない

アグリノートのコピー「4軒に1軒が使っている」を検算すると、母数によって **3.4%（全経営体）／12.3%（データ活用24.5万）／32%（93,200という別の値）** と割れ、**ちょうど25%になる母数（約12万）はどの統計とも一致しない**。加えて単位が「軒」ではなく「**組織**」で、JA生産部会・法人・集落営農が1組織として数えられうる。**競合ベンチマークとして使えない。**

## 3. 2万DL の位置

| 母数 | 2万DL の比率 |
|---|---|
| 農業経営体 82.8万 | **2.4%** |
| 基幹的農業従事者 102.1万人 | 2.0% |
| データ活用経営体 24.5万 | 8.2% |

**DL ≠ 利用者。** 唯一 両方を公表している畑らく日記は **実ユーザ／DL ≒ 25%**。これを当てると **2万DL ≒ 実利用者5千人 ≒ 全農業経営体の0.6%**。

**そして速度。** 1年で2万は、アグリハブ（3年半）の**3.5倍速**、KSAS（5年）の**5倍速**。現役農家が作って口コミで広げたアプリと、国内最大の農機メーカーの販売網に乗ったサービスの、それぞれ3〜5倍の速さで走る設定になる。

## 4. 伸びた事例が挙げている理由は、全部アプリの外にある

- **アグリハブ**: 「JAのアクセラレーター（2期）への採用も、農家さんの安心感に繋がり、**利用者が一気に増えるきっかけ**になりました」「宣伝広告費を一切使わずに、口コミで広がり」
- **KSAS**: クボタ本体の販売網
- **アグリノート**: 井関農機との資本業務提携
- **レイミー**: KSASマーケットプレイス、JA全農 Z-GIS 連携

**公表事例4件が4件とも、既存の信頼チャネル（JA・農機メーカー・農薬メーカー）への接続を成長の説明変数にしている。** UI改善や機能追加を理由に挙げた事例はひとつも見つからなかった。

## 6. 結論: 律速は「外の獲得経路」であって、アプリの中の作りではない

理由は3つ。

1. **母数が小さい。** 2万は全経営体の2.4%。バイラルで一気に増えるレンジではなく、**24.5万の中から1割弱を1年で連れてくる営業の数字**。Zaim 30万DL・NauNau 450万DL といった個人開発の成功例は母数1億の市場の話で、参考にならない
2. **伸びた事例の説明変数が全部外にある**（4件が4件とも既存チャネルへの接続）
3. **速度が3.5〜5倍。** この差をUX改善で埋めた事例は見つからなかった

### では UX は何に効くのか（3つに分かれる）

| | 効くか | 説明 |
|---|---|---|
| ストアページに来る人数 | **効かない** | 完全に外部要因。UXが良くてもインストール画面を見る人は増えない |
| ストア到達後の転換率 | **効く。ただし乗数** | ★2→★4 で5.4倍。**流入が月100人なら5.4倍でも年6,480で2万に届かない**。チャネルを獲った後に効く順序依存の要素 |
| **提携審査の資格要件** | **効く（間接）** | JA・農機メーカー・自治体は提携判断でストア評価とレビューを見る。アグリハブは「レビュー1位」を掲げて JAアクセラレータに採択された。**★4未満だと提携の話が始まらない**、というボトルネックの形で効く |
| DL→実利用の歩留まり | **効く。ただしKPIに乗らない** | 畑らく日記は DLの75%が消える。ここはオンボーディングの領域だが、**DL数をKPIにする限りUX投資は指標に反映されない** |

### KPIそのものへの疑い

業界の主要プレイヤーは揃って**DL数ではなく登録者数・利用組織数で語っている**（アグリノート「3万組織」、アグリハブ「登録者5万人」、KSAS「会員26,400人」）。畑らく日記の25%比率を踏まえると 2万DL＝実ユーザ5千人＝全経営体の0.6%。

**本当に欲しいのが「使われている状態」なら、目標をDL数ではなく実利用組織数に置くべきで、その場合はUXの重みが逆転する。**
