## 読むときの注意

- **「検証の強さ」を必ず見ること。** DR-01/02/04/05/06/10/11 は一次情報または3票検証を通っているが、DR-03/07/08/09/12 は**単体エージェントによる軽量版**で、推定値が多い。
- **各レポートが自分で「未取得」と書いている項目を、推測で埋めないこと。** 特に DR-07 の脱落率・DR-08 の季節変動・DR-09 の事例数値は実測ではない。
- **分母の定義が違う数字を横に並べないこと**（DR-10 §1）。
- 調査間で記述が食い違う場合は、一次情報に到達しているほうを優先する。具体的には、決済手段は DR-02 ＞ DR-07、ストアレビュー本文は DR-05 ＞ DR-12。
