# farm-app デザイン刷新ブリーフ：ソフトウィジェットスタイル

> このファイルは実装用プロンプト。新しいセッションにそのまま渡しても、
> このリポジトリの文脈だけで実行できるよう自己完結で書いてある。

## 0. ゴールと参照スタイル

kishu-farm（React + TypeScript + Vite、インラインスタイル、Tailwind不使用）の
全画面を「ソフトウィジェット」スタイルに刷新する。
参照は Notion Calendar / Family / Linear 系の日付・時刻ピッカーUI。

このスタイルの本質（すべての判断はここに帰着させる）：

- **構造は無彩色**。白いカード、ごく薄いクールグレーの背景。緑がかった灰色は全廃
- **アクセントは1色を「塗り」で**。選択状態と主ボタンだけが濃色。1画面に塗りは1〜2箇所まで
- **枠線ではなく、影と面の色差で階層を作る**。border は原則廃止
- **深い角丸**。カードは大きく丸く、ボタンは完全なピル
- **ラベル小・値大**の2段タイポグラフィ
- **余白 > 部品**。詰めない

### 現行との差分（重要な方針転換）

CLAUDE.md の旧方針「影で囲まず線とコントラストで構造化」「角丸8px」は**廃止**する。
実装完了時に CLAUDE.md のデザイントークン節をこのブリーフの内容へ書き換えること
（これを忘れると将来のセッションが旧方針へ引き戻す）。

## 1. デザイントークン（`src/ui/tokens.ts` を全面改訂）

色はすべてこのファイルに集約済み。他ファイルでの直書きは禁止（現状維持）。

### 1-1. サーフェス（3層構造）

| トークン | 値 | 役割 |
|---|---|---|
| `bg` | `#F5F5F6` | ページ背景。最下層のクールグレー |
| `well` | `#EFEFF1` | 「受け皿」。グループ入力の外枠、ホイールの溝、アイコンボタンの円 |
| `card` | `#FFFFFF` | 浮き面。カード・モーダル・入力行 |

構造の原則：**bg の上に card が浮き、card の中に well が凹み、well の中に card の行が浮く**。
この入れ子（白→灰→白）が参照スクショのグループ入力の正体。

### 1-2. インク（アクセント）

| トークン | 値 | 役割 |
|---|---|---|
| `ink` | `#2E7D32` | ブランド緑（明るめ・高視認）。選択日の塗り・主ボタン・アクティブ状態。白文字コントラスト約4.9:1でAA準拠 |
| `inkPress` | `#256628` | ink の押下時 |
| `inkSoft` | `#E4F0E4` | 面選択（フィルタ選択・月レンジ）の淡い塗り。文字は ink |

ブランドの緑はこの3つに集約。**淡緑チップ・淡緑背景ボックス（旧 primary3/primary4 の装飾用途）は全廃**。
ネイビー系に振りたくなったら `ink` 系3トークンの差し替えだけで済む。

### 1-3. テキスト・線

| トークン | 値 | 役割 |
|---|---|---|
| `text` | `#1A1C1E` | 見出し・値。純粋な墨色（緑みなし） |
| `textSub` | `#66696E` | 本文・説明 |
| `textMuted` | `#9EA1A6` | ラベル・プレースホルダ・非活性 |
| `hairline` | `#EBEBED` | 最後の手段としての区切り線。ボタン secondary の枠 |

旧 `border`（緑灰 #dde8dd）は hairline に置換。ただし**カードの輪郭には使わない**（影で描く）。

### 1-4. セマンティック（状態表示専用。装飾禁止）

| トークン | 値 |
|---|---|
| `danger` / `dangerBg` | `#D4453C` / `#FBEBEA` |
| `warning` | `#DD8A0A`（未報告バッジ等） |
| `info` | `#3773E1` |
| `pesticide` | `#7B1FA2`（農薬カテゴリのアイコン・文字色のみ。背景塗り禁止） |
| `temp` / `rain` | `#E07020` / `#0288D1`（天気アイコンのみ） |

### 1-5. 影（構造の主役）

`src/ui/tokens.ts` に shadow トークンを追加：

```ts
export const SHADOW = {
  card:  "0 1px 2px rgba(16,17,20,0.04), 0 8px 24px rgba(16,17,20,0.06)",  // 通常カード
  float: "0 12px 40px rgba(16,17,20,0.14)",                                 // モーダル・ピッカー
  pill:  "0 2px 8px rgba(16,17,20,0.10)",                                   // FAB・浮きボタン
} as const;
```

原則：**影とborderを同じ要素に併用しない**。カードは影のみ。well は影なし（色差のみ）。

### 1-6. 角丸

```ts
export const RADIUS = {
  card: 20,   // 外側カード・ボトムシート上角(24)
  row:  14,   // 入力行・リスト行・日付セル(12)
  well: 18,   // 受け皿
  pill: 999,  // ボタン・チップ・FAB
} as const;
```

## 2. タイポグラフィ

System フォント維持。階層は次の5段のみ：

| 役割 | サイズ/ウェイト | 色 | 備考 |
|---|---|---|---|
| 画面タイトル | 17px / 700 | text | |
| 値・行タイトル | 16px / 600 | text | ラベルの直下に置く |
| 本文 | 14px / 400 | textSub | |
| ラベル | 11px / 500 | textMuted | 値の上。曜日・見出しラベルは `letterSpacing: 0.08em` |
| 大数値 | 24px / 700 | text | 統計カード。単位は 11px textMuted |

**「ラベル小（灰）＋値大（墨）」の2段パターンを全入力・全統計で徹底**する。
これが参照スクショの "Date / July 16, 2026" の正体。

## 3. コンポーネント規則

既存の共通基盤（`src/ui/styles.ts` の `btn()`、`src/ui/BottomSheet.tsx`、`src/ui/RowMenu.tsx`）を
このスタイルに改訂して使う。新規パターンは以下。

### 3-1. ボタン（`btn()` を改訂）

- **primary**：ink 塗り・白文字・完全ピル。`padding: 14px 28px`。影 pill。**1画面1個**
- **secondary**：白背景・hairline 枠・text 色・完全ピル。Back/キャンセル役
- **tertiary**：文字だけ（textSub）。「条件をクリア」等
- **danger**：danger 塗り・白文字・ピル。削除確定のみ
- フッターの2択は `[Back(白)] [Apply(ink)]` の横並び、gap 10px。参照スクショの形
- 塗り緑ボタンの隣に塗り緑ボタンを置かない

### 3-2. グループ入力（新規パターン。クイック記録モーダルの主役）

```
┌ well (radius 18, padding 6) ────────────┐
│ ┌ card行 (radius 14, padding 14 16) ──┐ │
│ │ ラベル11px灰                  ○アイコン│ │
│ │ 値16px墨600                          │ │
│ └──────────────────────────────────────┘ │
│   ↕ 6px                                  │
│ ┌ card行 ──────────────────────────────┐ │
└──────────────────────────────────────────┘
```

- 未入力の行：値の位置にプレースホルダ（textMuted）
- 行右端のアイコンボタン：32px 円形、well 色背景、アイコン 16px textSub
- 入力済みの行：右端アイコンが編集(Pencil)に変わる

### 3-3. カレンダー（`DatePicker.tsx` / `CalendarView.tsx`）

- 白カード・影 float・radius 20。枠線なし
- 曜日ヘッダ：11px / textMuted / letterSpacing 0.08em（「月 火 水」も字間で伸ばす）
- 日セル：44px タップ領域。選択日＝ **ink 塗りの角丸四角(12px)・白文字・700**
- 今日＝数字の下に 4px の ink ドット（塗らない）
- 記録がある日＝textMuted の 3px ドット
- フッター：`[戻る(白ピル)] [決定(inkピル)]`

### 3-4. ボトムシート（`BottomSheet.tsx` 改訂）

- 上角 radius 24、影 float、つまみバー維持（well 色）
- ヘッダーの**アイコン入り色付きチップは全廃**。タイトル 17px/700 のみ＋右端に閉じる円ボタン（well 背景）

### 3-5. リスト（農薬・作物・圃場・ユーザー）

- 個別ボーダーカードの縦積みを廃止
- **1枚の白カード（影 card・radius 20）の中に行を積む**。区切りは hairline 1px（左右 16px インセット）
- 行：タイトル 15px/600 text、メタ 12px textMuted、右端に RowMenu
- 空状態：well 背景の角丸ボックスに textMuted で説明＋次の行動

### 3-6. FAB・ナビ

- FAB：ink 塗りピル「＋ 記録」、影 pill。位置は現状維持（右下、ナビ上）
- ボトムナビ：白・上 hairline。アクティブ＝ink 色の文字＋アイコン（上ボーダー3pxは廃止し、色だけで示す）

### 3-7. 情報ボックス（天気等）

- 淡緑背景＋淡緑枠 → **白 card 行 or well 行**に変更
- 色はアイコンだけが持つ（temp/rain/info）。テキストは text/textSub

### 3-8. チップ・バッジ

- フィルタチップ：非選択＝白＋hairline＋textSub、選択＝inkSoft＋ink 文字。完全ピル
- ロール/状態バッジ：色文字＋inkSoft 系の淡背景は可（状態表示なので）。装飾チップは不可

## 4. 禁止事項（AI感の源。レビューで grep する）

1. 緑がかったニュートラル（#f4f7f2, #dde8dd, #8aaa8a, #4a6a4a, #1a2e1a 系）
2. アイコン入りの色付き角丸チップ（ヘッダー装飾）
3. 淡色背景＋同系淡色枠のボックス
4. 同一要素への border ＋ boxShadow 併用
5. 1画面に塗りボタン複数
6. グラデーション、過剰なアニメーション

## 5. 実装手順（段階コミット。各段で lint＋tsc＋スクショ確認）

1. `tokens.ts` 全面改訂＋ SHADOW/RADIUS 追加。旧トークン名は互換エイリアスで残して段階移行
   （`primary`→`ink` 等。最終段で旧名を削除）
2. `btn()` ピル化、`BottomSheet` radius/影/ヘッダー改訂、`RowMenu` 追随
3. クイック記録モーダルをグループ入力パターンで再構成（最重要画面。ここで見た目を確定させる）

5. 管理タブのリスト3種＋ホームのカード/統計を 3-5・2 の規則へ
6. ナビ・FAB・ヘッダー・ログイン画面
