# ヒアリング質問票（事業定義の検証）

- 作成: 2026-09-29
- 目的: `docs/business-definition.md` の仮説 H1〜H3 を、**アプリを見せる前に**確かめる
- 順番: ①自分の農場のベテラン → ②自分の農場の新人 → ③出荷先 → ④他の農家3〜5人

## 聞き方の決まり（これを外すと、答えが全部お世辞になる）

1. **アプリの話を先にしない。** 「こういうアプリがあったら使う？」は聞かない。ほぼ全員が「使う」と答え、実際は使わない
2. **意見ではなく、過去の出来事を聞く。** ✕「困っていますか」 ○「最後に困ったのはいつ？ そのときどうした？」
3. **その人が今どうしているかを聞く。** 手帳、カレンダー、記憶、人に聞く、JAの防除暦など。今の方法でお金や時間を使っているなら、課題は本物
4. **黙って待つ。** 沈黙の後に本音が出る
5. **その場で記録する。** 下の記録シートに、相手の言葉をそのまま書く（要約しない）

## ① ベテラン向け（H1: 記憶で判断してズレた経験があるか）

所要: 10分。作業の合間でよい。

1. 「◯◯（最近撒いた農薬）、前回撒いたのはいつでしたっけ？」
   → **答えを記録と照らし合わせる**。ここが一番大事。ズレていても指摘せず、あとで記録シートに書く
2. 「今年この畑でその農薬、何回目ですか？」 → これも記録と照合
3. 「前回いつ撒いたか、普段は何で確かめてます？」（記憶／手帳／カレンダー／JAの資料）
4. 「撒いた日や回数を勘違いして、あとで気づいたことはありますか？ 最後はいつ？」
5. 「新しく入った人に、作業のことをどのくらい聞かれます？ 最後に聞かれたのは何？」
6. 「自分が休んだら、誰が農薬のことを判断します？」

**H1 が支持される**: 1・2 で記録とのズレが出る、または 4 で具体的な出来事が出る
**H1 が否定される**: 記録とほぼ一致し、4 も「無い」

## ② 新人・経験の短い人向け（H2: 作業前に人に聞いているか）

所要: 10分。加えて、1週間のメモをお願いする。

1. 「今日やる作業は、どうやって決まりました？」
2. 「最後に誰かに作業のことを聞いたのはいつ？ 何を聞きました？」
3. 「聞きたかったけど聞けなかったことはありますか？ そのときどうしました？」
4. 「農薬を撒くとき、何を・どれだけ・何倍で、はどうやって知りました？」
5. 「スマホで調べることはありますか？ 何で調べました？（検索・YouTube・生成AIなど）」

**1週間のメモ**（紙1枚でよい）: 「作業のことで誰かに聞いた／調べた」たびに、日付・何を・誰に（何で）を1行書く。

**H2 が支持される**: 週に数回以上聞いていて、聞かれた側（ベテラン）の手が止まっている
**H2 が否定される**: ほぼ聞いていない（段取りは管理者が全部決めて渡している）→ その場合、買う理由は「新人の分からない」ではなく管理者側にある

## ③ 出荷先への確認（H3: 防除記録を求められるか）

電話かメール。1〜2分。

1. 「防除の記録（農薬の使用記録）の提出や確認を求められることはありますか？」
2. 「ある場合、どんな形式ですか？（指定の用紙／自由形式／見せるだけ）」
3. 「いつ・どのくらいの頻度で？」

## ④ 他の農家向け（3〜5人）

候補: 近隣農家、研修で知り合った人、既に Web 版を使っているもう1つの農場。
①②の質問から相手に合うものを選び、最後に次を足す。

1. 「一緒に作業している人は、何人・どんな経験の人ですか？」
2. 「作業の記録は今何でつけてます？ 誰がつけてます？」
3. 「出荷先から防除の記録を求められますか？」（H3）
4. （最後にだけ）「もしよければ、使ってみてもらえる記録アプリがあるんですが、試してもらえますか？」
   → **その場で作業者アカウントを渡せるか**が本当の答え。「今度ね」は No と数える

## 記録シート（1人1枚）

```
日付:            相手: ベテラン／新人／出荷先／他農家（経験◯年・作目◯）
H1 前回散布日  本人の答え: ____  記録: ____  ズレ: 有／無
H1 使用回数    本人の答え: ____  記録: ____  ズレ: 有／無
今の確かめ方:
最後に困った出来事（相手の言葉のまま）:
人に聞いた／聞かれた回数（1週間）:
防除記録の提出: 有（形式: ____）／無／不明
試してもらえるか: その場で渡せた／後日／断られた
```
