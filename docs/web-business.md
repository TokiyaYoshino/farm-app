# Web事業のドキュメントについて

kishufarm の **Web事業**（HP制作〜AEOマーケ支援）の資料は、このリポジトリではなく
[kishufarm リポジトリ](https://github.com/TokiyaYoshino/kishufarm) の `docs/web-business/` にあります。

Web事業は farm-app とは別の事業ラインのため、そちらを正としています。
このファイルは、farm-app から探しに来た人のための道しるべです。

## なぜ farm-app に関係があるか

farm-app の [`docs/adr-001-multitenancy-and-ai.md`](adr-001-multitenancy-and-ai.md) には、
マルチテナント化（SaaS化）の開発工数について
「会員権・Web/AEO事業の稼働と競合しないタイミングを見極める」との記載があります。

**Web事業と farm-app は、代表の稼働時間を取り合う関係にあります。**
Web事業側の調査で、半年 +5〜8件という目標が代表の月92時間を要求することが分かっており
（月60時間を割いても届くのは3.9件）、farm-app の開発計画を立てる際はこの前提を踏まえてください。
