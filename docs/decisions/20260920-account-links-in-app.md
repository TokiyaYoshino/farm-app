# アプリ内にポリシーとアカウント削除の導線を置く

- 日付: 2026-09-20
- 状態: **採用**
- 種別: 仕様変更（画面フロー・審査対応）
- 関連: `docs/app-store-submission.md` 7章、`docs/decisions/20260912-release-line.md`（3問の①）

## 課題（Why）

申請前の最終確認で、**アカウント削除の導線がアプリにもWebにも存在しない**ことが分かった（`expo-prototype/` と `src/` を横断して該当なし）。

ガイドライン 5.1.1(v) は、アカウントを持つアプリに削除の導線を求める。`docs/app-store-submission.md` 7章はこれを「ログイン必須の正当性」とだけ読んでいて、**削除要件に触れていなかった**。読み違いが申請書類側に残っていた。

これは `20260912-release-line.md` の3問①「直さないと審査で落ちるか」に当たるため、機能追加の凍結の外側として扱う。

## 決めたこと

ユーザーシート（`expo-prototype/App.tsx`、これまでログアウト1つだけだった）に、1枚のカードで2行を置く。

```
[ 名前 / 役割 ]
┌─────────────────────┐
│ プライバシーポリシー      │
│ アカウントの削除         │
└─────────────────────┘
  ログアウト（既存）
  バージョン 0.1.0
```

- **削除はアプリ内で実行しない。** `public/privacy.html` に 7章「アカウントの削除」（`#account-deletion`）を新設し、そこへ飛ばす。手順は「所属農場の管理者に依頼する」か「問い合わせ先に氏名とログインIDを添えて連絡する」の2つ
- URLは `expo-prototype/lib/links.ts` の1箇所に集約する（ドメイン変更時に1ファイルで済む）
- バージョン表示は `Constants.expoConfig?.version` から取る（問い合わせ時にビルドを特定するため）

## 検討した代替案

- **アプリ内で実削除まで実装する** → 見送り。アカウントを発行するのが管理者なので、削除も管理者側（Web）で行うのが運用と一致する。Supabase 側の削除処理まで要り、「機能追加はしない」方針にも抵触する
- **何も入れずに出し、5.1.1(v) で落ちたら対応する** → 見送り。アプリ内に新規登録が無いため条文上は該当しない可能性もあるが、**例外は保証されない**。審査1往復（数日）を賭ける理由が今は無い
- **ABM の Unlisted App で限定配布する** → 見送り。論点自体は消えるが、一般公開という方針の変更になる

## 影響範囲

- **DB / RLS**: なし。削除処理は実装していない
- **既存機能**: 削除なし。ユーザーシートに行が増え、`heightRatio` を 0.4 → 0.52 にした
- **AppStore / 法規**: 5.1.1(v) 対応。**課金を入れた時点で、アプリ内の規約・ポリシーへのリンクは Apple の must になる**（`docs/research/dr-2026-09/DR-06-payment-setup-lead-time.md` §1.3(b)）ので、この導線はそのとき再利用できる
- **未完**: `public/privacy.html` 10章の運営者名・問い合わせ先メールは **TODO のまま**。このアドレスは削除の受付窓口を兼ねるので、**実際に届いて返信できるアドレスであること**が要件になった

## プレモータム

1. **削除依頼のメールが届いても誰も見ず、放置された。** Apple は導線の有無しか見ないが、実際に依頼が来たときに運用が無いと、レビューや通報の形で跳ね返る
2. **ドメインを kishufarm.com に移したときにリンクが切れた。** → `links.ts` 1箇所に集約して緩和済み
3. **「手順の提示」では不十分と判断され、5.1.1(v) でリジェクトされた。** → その場合はアプリ内実削除に切り替える。判断材料は Resolution Center の文面

## 過去の判断との関係

- `20260912-release-line.md` の「App Store に必要な機能開発はゼロ」を部分的に補正する。機能開発ではないが、**審査ゲート（3問の①）に当たる実装が1件あった**
- `docs/app-store-submission.md` 7章の 5.1.1(v) の記述を訂正した（「ログイン必須の正当性」のみ → 削除導線を含む）
- 文言は `20260909-ai-wording-and-icons.md` に従い、別画面へ移動するだけの行なので体言止め（「プライバシーポリシー」「アカウントの削除」）
