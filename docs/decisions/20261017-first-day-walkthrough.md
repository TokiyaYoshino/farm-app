# 新人の初日をなぞる確認と、そこで直したもの（2026-10-17）

## やったこと
Expo版をシミュレータで、新人のつもりで通しで操作した（紹介 → 記録 → 防除の記録 → 相談 → 分析）。
アカウントは管理者（吉野）のまま。保存はしていない。
見られていないもの: 自分の記録が0件のときのホーム、作業者の権限で見える範囲、管理タブ（TestFlight で配る前に作業者のテスト用アカウントで確かめる）。

観点は6つ: 開いてすぐできるか／初めての人が迷わないか／詰め込みすぎていないか／屋外で使えるか／言葉が揃っているか／見た目の決まりに沿っているか。

## 直したもの

| # | 画面 | 何が起きていたか | 直し方 |
|---|---|---|---|
| 1 | 防除の記録 | 農薬の欄が「使用農薬（任意）」で「詳細を入力」の一番下にあり、そのまま記録すると農薬名の無い防除の記録ができた（必達③・法令の記帳が欠ける） | 農薬の欄を詳細の外に出し「使った農薬」に。農薬を選ばずに記録するときは一度確かめる（防虫ネットなど農薬を使わない防除もあるので止めはしない） |

- 管理タブ3つの全面的な統一（一覧を先・追加はシート）も案に出したが、オーナーが「圃場の形がきれい」として作物を圃場に合わせる形を選んだ。農薬の一覧（1枚のカード）と文字リンクの色（青と緑の混在）は今回は触っていない
- 圃場マップ: 本番の圃場は位置が未設定（C・D圃場とも「位置未設定」）で、マップを開いてもピンは0本だった。棚卸しの「確かめること」の1つ目はこれで答えが出た
- 「見張れません」は 2026-08-24 に「何を失うかを書く」と決めた言葉なので残した（`20260824-plain-language-and-crop-mapping.md`）
- ログインの欄が日本語入力で開き「kishu」が「きしゅ」になる不具合も同じ日に直した（英字キーボードで開く）

## 審査対応: 外部のAIに送る前の同意（2026-10-17 追記）
- 審査ガイドライン 5.1.2(i)（2025-11-13 追加）は、個人データを外部のAIに送るなら、アプリ内で知らせて送る前に同意を取ることを求める。プライバシーポリシーへの記載だけでは足りない
- Expo版のAI呼び出しはすべて `lib/ai.ts` の `callApi` を通るので、そこで1回だけ確認を出す（`lib/aiConsent.ts`）。同意は利用者ごとに端末へ残す。断ったら送らずに理由を出し、もう一度押せば選び直せる
- 取り消しは利用者シートの「外部のAIへの送信」
- Web版は未対応（審査の対象はアプリだけ。Web版へ移すかは Expo版の形が固まってから）

## 同意はインストール後の最初の画面で聞く・長文を削る（2026-10-17 追記）
- 同意は、AIの機能を押したときではなく、ログイン後の最初の画面（`screens/AiConsentScreen.tsx`、紹介より前）で1人1回聞く。中身は「送るもの・送り先・学習に使われない」の3行だけ。断った人には、AIの機能を押したときにもう一度聞く
- オーナーの「美しい」の2つ目: **グレーの長文や分かりにくい説明を置かない。** 初めての人が、どこに何があり何を押すかを見ただけで分かる形にし、補足は短文1行まで
- これに合わせ、画面に出る長文9か所を1行に縮めた（次の散布時期の説明・アカウント削除・照合できません・収支の注記・作業暦の案内・作物未選択・圃場マップ・同意の取り消し・農薬の確認）

## 説明文の見せ方を他のサービスに合わせる（2026-10-17 追記）
- 冒頭の説明文は置かない（相談タブ・相談シート）。会話が空のときだけ、聞ける例を押せるボタンで3つ出す（ChatGPT 等と同じ見せ方）
- 状態は印で出し、理由は押したときだけ（農薬の使用状況。「超過の疑い」の文だけは常に出す）
- できないことは書かず、できる操作だけ置く（計画:「Web版で編集 →」。期間外の件数は期間の横に数字だけ）
- 作業暦の案内文、作物の「ラベル上の作物名」の説明文、相談の返答ごとの「メモに入ります」の補足を消した
- 相談の農薬の登録原文（FAMIC）も、表示するときだけ半角カナを全角にする（`dispName`）

## 農薬の適用情報を作物ごとに1枚へ（2026-10-17 追記）
- 散布前に見る順（使用基準）で並べる: 自分の作物 → 使用時期 → 回数 → 総使用回数 → 希釈 → 病害虫。ラベルの内容と自分の使用回数を同じ1枚に（`ui/PesticideCropCards.tsx`）
- 作っていない作物の登録は「ほかの作物の登録（◯件）」に畳む。30件で切っていた上限はなくした
- FAMIC 原文が空や「-」の項目は「記載なし」と出す
- 注意書きは「使う前に、必ず製品ラベルを確認してください」の1行だけ
- 計画の「Web版で編集」は外した。計画の扱いはリリース後に決める（`docs/roadmap.md` 保留）
