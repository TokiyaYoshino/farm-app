# 都道府県の防除暦の取り込みは、法務ゲートで一旦止める（京都府で調査）

- 日付: 2026-09-06
- 状態: 保留（着手しない。前提が変われば再検討）
- 種別: 調査・意思決定（外部データの取り込み）

## 課題（Why）

相談機能の返答のうち、一般的な栽培知識（作業の段取り・時期）だけが参照元を持たず LLM の推論のままだった（`docs/decisions/20260906-advice-reply-tone.md`）。農薬の使用基準は FAMIC 原文、自農場の事実は自分の DB という一次情報があるのに、3層目だけが推測になっている。

オーナーから「推論では農業エージェントとして成立しないので参照元を探す必要があるのでは」という指摘があり、**いま画面で「地域の栽培暦を優先してください」と誘導している当のもの＝都道府県が公開する防除暦・栽培暦を取り込む**方向を検討した。着手の順序は「安く殺せるものから」で、法務ゲート → 対象の確定 → 一次情報の形と更新 → 設計 → 検証、と合意している。

対象地域は京都府（`docs/roadmap.md` のオーナー情報のとおり霧珠ファーム）。

## 調べて分かったこと

### 1. 京都府のホームページに包括的な二次利用の許諾が無い

[京都府ホームページの著作権](https://www.pref.kyoto.jp/copyright.html)は「**私的使用のための複製」や「引用」など著作権法上認められた場合を除き、無断で複製・転用することはできません**」とあり、政府標準利用規約／公共データ利用規約（CC BY 4.0 互換）を採用していない。全文をDBに取り込んで配信する形は、許諾を取らない限り採れない。

### 2. そもそも「防除暦」は公開されていない

[京都府病害虫防除所](https://www.pref.kyoto.jp/byogai/)が公開しているのは、発生予報・注意報・特殊報・防除所ニュース・技術情報・巡回調査結果など、**「今この病害虫が出ている」という時系列の情報**であって、作物×時期×作業の年間の暦ではない。[農作物病害虫・雑草防除の基本方針](https://www.pref.kyoto.jp/nosan/1210555175002.html)にも防除暦にあたる文書は見当たらない。

**防除暦はJAが作成・配布していることが多く、その場合は農協の著作物で使えない。** 「都道府県が防除暦を公開している」という当初の前提自体が、少なくとも京都では成り立たない。

### 3. 通るのは国の資料だが、目的には弱い

[農林水産省のコンテンツ](https://www.maff.go.jp/j/use/link.html)は公共データ利用規約（第1.0版・CC BY 4.0 互換）で、出典表示と改変明示をすれば複製・改変・商用利用ができる。ただし総合防除実践マニュアル等は全国一般の内容で、**今回埋めたかった「地域差」は埋まらない**。

## 決めたこと

**取り込みには着手しない。** 1と2で前提が崩れており、設計（データモデル・更新運用）に進む意味が無い。

代わりに、価値の芯だけを著作権の問題が起きない形で拾う余地がある。

- 京都府の**予察情報**は「今この病害虫が府内で出ている」という一次の事実で、相談の材料としては暦より鮮度が高い。ただし全文取り込みではなく、**出典としてリンクで誘導する**（引用の範囲を超えない）なら許諾の問題は生じない
- ただしこれは `docs/decision-log.md`（2026-07-31）で**一度分離した項目**でもある（「予察情報はPDF中心でAPIが無く、自動化が脆いため次段の別仕様」）。同じ壁に当たっている

## 検討した代替案

- **農水省の資料だけを取り込む** → 見送り。ライセンスは通るが地域差を埋められず、目的を果たさない
- **JAの防除暦を使う** → 不可。農協の著作物で、包括的な二次利用の許諾は通常ない
- **京都府に利用許諾を申請する** → 可能性はあるが、個人開発で1品目の検証も済んでいない段階でかける手間としては重い。**検証（下記）で価値が確認できてから**にする
- **web検索を都度繋いで拾う** → 却下。出典が固定されず追跡できないうえ、農薬の数値のような法令に関わる情報では一次情報の正確な引用を保証できない（`20260906-advice-reply-tone.md` の三層の切り分けと矛盾する）

## 影響範囲

- **DB / 権限 / 既存機能**: なし（着手しないため）
- **相談機能**: 3層目（一般的な栽培知識）は推論のまま残る。画面では「目安」と明示し、地域の指導機関の栽培暦を優先するよう誘導している現状を維持する
- **ストア審査 / 規制**: なし

## 前提が変わったら再検討する条件

1. 京都府（または対象地域）が防除暦にあたる文書を、公共データ利用規約で公開した
2. 利用許諾を取る価値があると判断できるだけの利用実績が出た
3. 予察情報の「リンクで誘導する」形だけを小さく試して、実際に使われることが確認できた
