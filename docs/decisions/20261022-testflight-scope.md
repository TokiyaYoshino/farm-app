# TestFlight（0.1.0）でテスターに見せる範囲を絞る（2026-10-22）

## 決めたこと
Expo版の TestFlight 配信の前に、毎日使わないのに目立つ場所にある入口を2つ外す。**コードは残す**（CLAUDE.md「機能は削除しない」）。

| 外したもの | 場所 | 残したもの |
|---|---|---|
| 計画（ガント） | 分析タブのサブタブ | `GanttScreen` と `App.tsx` の分岐。Web版の計画はそのまま |
| 「作業を開始」（タイマー） | ホーム「今日の予定」 | store の `startWork` / `stopWork` と、動作中の表示・停止 |

## なぜ
- 全機能の棚卸し（`20261010-feature-inventory.md`）で、どちらも「奥に下げる候補」。押されている証拠が無い（タイマー）、worker 0人で使われ方の判断材料も無い（計画）
- 計画はアプリでは見るだけで、10/17 に「Web版で編集」の案内を外したため、テスターが開いても何もできない画面になっていた
- 計画を外したので、縦持ちのときの青い帯（「横向きにすると…」）は見えなくなる。帯そのものは触らない

## 後に回したもの（TestFlight でテスターに触ってもらってから決める）
- **ホームの作り直し**（見本 `docs/mock-home-crops.html`）：2回「微妙」と言われていて、`20260912-release-line.md` の3問のどれにも当たらない
- **防除の記録シートの使用状況を、管理→農薬と同じ形に揃える**：同上
- **課金の組み方**（RevenueCat／StoreKit）：TestFlight には要らない。App Store の審査に出す前に決める

## 戻す条件
- 計画：アプリで追加・編集できるようにすると決めたとき（`docs/roadmap.md` に積んだ判断）
- タイマー：テスターから「作業時間を自動で入れたい」と出たとき
