# 収益モデルの比較と方針転換：B2Cサブスク単体から「束ねる側への提供」へ

- 日付: 2026-09-05（2026-09-06 に制約反映・方針確定）
- 状態: **採用（方向性の決定。料金プランの具体値は未決定）**
- 種別: 事業戦略の転換
- 関連: `20260905-net-income-target-contract-count.md`（必要契約数の試算）、`20260823-pricing-plan-review.md`（課金軸の論点）、`docs/roadmap.md`

## 課題（Why）

`20260905-net-income-target-contract-count.md` で「手元に月30万円」に必要な契約数を**約674件**と算定した。
この数字が達成可能かを判定し、達成できないなら代替の収益モデルを選ぶ。

## 判定1：Pro 980円のB2Cサブスク単体では非現実的

### 必要な母数

| 転換率 | 必要な無料ユーザー | 基幹的農業従事者98.7万人比 |
|---|---|---|
| 1% | 67,400人 | 6.8% |
| 2% | 33,700人 | 3.4% |
| 3% | 22,467人 | 2.3% |
| 5% | 13,480人 | 1.4% |

- 個人向けB2C SaaSの有料転換率は**1〜3%が標準、5%超で優秀**。前回試算の3%は楽観側の端
- 基幹的農業従事者は2026年に**初めて100万人を割り98.7万人**（前年比4.8%減）、平均67.7歳、**70歳以上が56.5%**、30代3.8%、29歳以下1.2%
- 実質の母集団は「データを活用した農業を行っている24.2万経営体」あたり。ここに22,000人なら**シェア9%**
- 先行者はアグリノート「4軒に1軒」・3万組織超、アグリハブ3万人超。**資金調達した企業が数年かけて到達した位置**
- 市場は年4.4〜4.8%ずつ縮小中

**結論：不可能ではないが、副業の時間配分で数年内に到達する確率は低い。目標が悪いのではなく、目標を載せる先が違う。**

`docs/roadmap.md` は当初から「アプリの位置づけ：単体の収益源ではなく、将来の農業コンサル事業に向けた関係構築・データ蓄積の入口」と書いていた。**この判断は正しく、月30万円をアプリ単体に載せたことがズレだった。**

## 判定2：同じ30万円を他モデルで取る場合の必要件数

税・手数料・経費を同条件で揃えた（本業課税所得300万、青色65万控除、必要事業所得421万/年）。

| モデル | 単価 | 必要件数 | 年間売上 |
|---|---|---|---|
| A. Pro 980円 / iOS IAP | 980円/月 | **656件** | 771万 |
| B. Team 2,980円 / Web | 2,980円/月 | **157件** | 560万 |
| C. 産地・JA向け管理画面 | 1万円/月 | **46団体** | 549万 |
| D. 産地・JA向け管理画面 | 3万円/月 | **15団体** | 536万 |
| E. 新規就農 顧問契約 | 3万円/月 | 16件 | 560万 |
| F. 新規就農 顧問契約 | 5万円/月 | 9件 | 543万 |

**656件と15件。40倍のレバレッジ差。** 副業の稼働時間で見ても、674件のサポート対応（1件5分/月でも56時間）より15団体×4時間（52時間）のほうが同じ時間で桁違いに稼げる。

## 制約：オーナーの農業経験が浅い（2026-09-06 追加）

**専門性そのものを売るモデルは選べない。** これは今後の全判断に効く前提として固定する。

| モデル | 判定 | 理由 |
|---|---|---|
| 新規就農コンサル・顧問（E・F） | ❌ 落ちる | 売り物が専門性そのもの |
| 栽培技術アドバイザー | ❌ 落ちる | 同上 |
| 行政へのデータ販売 | ❌ 落ちる | 専門性以前の問題（後述） |
| 補助金申請支援 | △ 保留 | 制度の専門性であって農業の専門性ではないが、経営計画の中身は書けない |
| **産地・部会・法人向けの束ね管理画面（C・D）** | ✅ **残る** | **買い手がすでに専門性を持っている** |

束ね売りが制約を通る理由：産地の事務局・部会長・農業法人の管理者に農業を教える必要はない。彼らはオーナーより農業を知っている。彼らが困っているのは「30戸分の防除記録が紙とExcelでバラバラで、締切前に集まらない」という**事務の問題**であり、これはIT側の問題。

売り物は「いつ何を撒くべきか」ではなく「**締切の日に全戸の記録が揃っている状態**」。

## 行政へのデータ販売を見送る理由

オーナーの当初案。以下4点で見送る。

1. **データが自社のものではない。** 農水省「農業分野におけるAI・データに関する契約ガイドライン」は、農業データについて農業者が希望すれば農業者に提供する条項を契約に入れることを求め、令和3年度から補助事業でスマート農機等を導入する際は**ガイドライン準拠が要件化**されている。二次利用には個別同意が必要
2. **量が足りない。** 政策判断には統計的代表性が要る。結局B2Cサブスクと**同じ母数の壁**に戻る
3. **行政は基本的にデータを買わない。** 都道府県は普及指導員を全国約7,100人・普及指導センター362カ所を自前で持ち、統計は農水省が無料公開。買う場合も「委託事業」＝単年度・入札・年度末納品で継続収益にならない
4. **既に商品化済み。** アグリノートマネージャーがJA・生産者団体・直売所・**行政**・食品メーカー向けに、年額12万円（Sプラン）＋生産者側年額2万円で販売中

**ただし発想の転換で強くなる：「データを行政に売る」ではなく「束ねる側に管理画面を売る」。** 生産者は無料で使い、産地・部会・農業法人・JAが払う。データ帰属の問題が消え（束ねる側が生産者と既に直接の関係を持つ）、母数の壁も消える（1団体で20〜50戸がまとめて入る）。

## 具体的な入口：GAP団体認証の事務局

JGAP団体認証では、団体事務局が「団体管理マニュアル」を作り帳票を揃え運営の記録を残す責任を負い、さらに内部監査（計画・チェックリスト作成・目揃い・全農場と事務局の監査実施・指摘の是正・是正確認）を回す必要がある。**これを今、紙とExcelでやっている。**

farm-app が出すのは農業知見ではなく「全戸の記録が最初から一箇所に集まっている状態」。認証の中身にはGAP指導員・認証コンサルという専門家が既におり、彼らは**記録が揃わないことに困っている側**なので競合ではなくチャネルになる。

### roadmap の過去判断との関係（覆さない）

`docs/roadmap.md` の「JGAP監査対応の拡充は、レビュー横断調査で要望がほぼ見られず需要の裏付けが弱いため保留（2026-07-22）」は**覆さない**。あの調査が見ていたのは**個人農家のアプリレビュー**であり、そこにJGAPの要望が無いのは当然。JGAPで苦しんでいるのは個人農家ではなく**団体事務局**であり、観測点が違っただけで需要の否定にはなっていない。実装の着手はヒアリング後（後述）。

## 市場の向き

| | 2015 | 2025 | 変化 |
|---|---|---|---|
| 農業経営体 | 137.7万 | 82.8万 | **▲4割** |
| 法人経営体 | 2.7万 | 3.3〜3.4万 | **＋22%** |

個人農家は消え続け、法人・団体だけが増えている。**980円を個人に売るのは縮む側への賭け、束ね売りは伸びる側への賭け。**

## 専門性は「売る」のではなく「借りる」

チャネル候補：普及指導員（全国約7,100人・普及指導センター362カ所）、GAP指導員・認証コンサル、JA営農指導員・部会事務局。
オーナーは「農業を分かっている人」である必要がなく、「**記録を集める道具を作れる人**」であればよい。

## 決定

1. **月30万円の達成手段を「Pro 980円のB2C積み上げ」から「産地・部会・農業法人など束ねる側への提供」に移す**（15〜46件）
2. **Pro 980円・Free は廃止しない。** 関係構築とデータ蓄積の入口として roadmap どおり維持する。目標を載せる先から外すだけ（CLAUDE.md「既存機能を削除しない」にも従う）
3. **月30万円という期限を farm-app に課さない。** このモデルでも年3〜5件が上出来で、素直に3〜5年仕事。開発力の受託収入とは財布を分けて考える
4. **専門性を売るモデル（コンサル・顧問）は選択肢から外す**

## 開発と営業の配分

**並行ではなく実質一本。** 束ね売りの商品価値は「全戸の記録が揃っていること」であり、価値の源泉は集約画面ではなく**現場の入力が続くこと**。入力UX改善・音声メモ構造化・マルチテナント化はそのまま束ね売りの投資になる。本当に増えるのは「束ねる側の画面1つ」と「営業」だけ。

| | 内容 | 配分 |
|---|---|---|
| 開発 | 今のまま（マルチテナント化が最優先） | 8割 |
| 営業 | 月2件のヒアリングを止めない | 2割 |

営業は投下時間より**継続性**が効く（対象15〜46件・リードタイム数ヶ月）。

### roadmap 優先順位の入れ替え

方針（「使い続けてもらえるアプリが短期の最優先」）は変更しない。同点のとき束ねる側に効くほうを先にする。

| 項目 | 変化 | 理由 |
|---|---|---|
| マルチテナント化 | 変わらず最優先 | 束ね売りの前提。組織＝産地・部会になるだけで設計は追い風 |
| 音声メモ構造化（AI#1） | 維持〜格上げ | 入力が続かないと束ねる先に何も溜まらない。生命線 |
| 農薬履歴 CSV/PDF帳票出力（AI#2） | **格上げ** | 事務局が監査に出す現物。売り物に直結 |
| 週次進捗AIサマリー＋LINE（AI#6） | **格下げ** | 「チーム進捗管理」の話で、事務局の「記録が揃わない」問題とは別 |
| 病害虫画像診断（AI#5） | **格下げ** | 専門性側の機能で、競合が無料で持っている |

`docs/roadmap.md` が「Team課金理由の本命」としていた #6 が下がり、「付加価値」扱いだった #2 が上がる。
