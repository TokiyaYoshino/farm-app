# 料金とアカウントを「農場ごと」から「1人ごと」に変える／先着100人は月980円

- 日付: 2026-10-08
- 状態: 採用（チームの人数追加の仕組みは未決・当面は個別対応）
- 種別: 仕様変更（料金体系・アカウントの形・回数の上限）
- 覆す判断: `20261001-pricing-freemium.md`（農場ごと月980円・人数無制限）、`20261001-account-model-self-signup.md`（登録すると農場ができ、管理者が人を加える）
- モック: https://claude.ai/artifact/KsqnDxu2UoqihShf8rfdJ1

## 課題（Why）

- **農場ごと・人数無制限は赤字が出る。** 原価（AIの呼び出し）は人数に比例するのに、売上は農場で1つ。10-01 の試算でも5人以上の農場は、全員がよく使う月に赤字だった。オーナー方針「設計上、最初から赤字なし」と合わない
- 1人1購読なら App Store の購読がそのまま使える（「管理者が買えば全員に効く」という特殊な扱いが要らない）

## 決めたこと（オーナー 2026-10-08）

| 項目 | 決定 |
|---|---|
| 単位 | **1人ごと**。アプリから登録できるのは個人。本人1人の環境（招待の画面は出さない） |
| 価格 | 無料／有料 **月1,480円**。**先着100人は月980円**（続けている限り据え置き） |
| チームの料金 | **1人の料金 × 人数**。支払いは**アプリ内課金** |
| チームで使う | **申請制**。人数の追加は**当面は個別対応**、仕組みは別途考える |
| お試し | 有料を**1週間無料**。無料の回数を使い切ったときに案内する（登録直後の料金画面は価格を見せるだけ） |
| 回数の上限 | **1人ごと**に数える（無料: 相談 週3件・写真 週1回／有料: 相談 1日8件・写真 1日3回。値は 10-01 のまま） |

### 先着価格の作り方
980円で出し、100人に達したら**新規の人だけ** 1,480円に上げる。App Store の値上げは「今の購読者は前の価格のまま」を選べるので、先着の人は自動で 980円に残る（オファーコード配布は不要）。

## 影響範囲

- **DB**: 個人も「1人の組織」として作るので、購読を組織に付ける設計（ADR `20261003-adr-signup-billing-deletion.md` 2節）はそのまま使える。回数の数え方だけ `organization_id` → 利用者ごとに変える（`api/_quota.ts` と契約テスト）。**2026-10-08 実装済み**: `checkOrgQuota` → `checkUserQuota`（`ai_outputs.created_by` で数える）、契約テストは `scripts/test-user-quota.mjs`（39件）。ADR 6節の「`organization_id` で数える」はこれで置き換え
- **画面**: 1-4「農場を作る」の「自分ひとり／何人かで」をやめる。3-1・3-2 の「先着100農場」「農場ごと」を「100人」「1人」に。4-1 の「働く人を招待」を「チームで使う（申請）」に
- **既存の農場**（オーナーの農場・asuka）: チームとして手で扱う。既存の利用者を締め出さない
- **審査**: チームの料金をアプリ内で払う＝人数分の購読をどう売るか（1人ずつ各自が買う／管理者が人数分買う）が未決。管理者がまとめて買う形は、App Store の購読に「数量」が無いため、人数ごとの商品を並べる必要がある
- **事業定義との関係**: 価値の中心はチーム（経験の違う人が同じ記録を見る）。申請を重くしない（アプリから送れて、すぐ返事が来る）ことを守る

## 未決
- チームの人数分を「各自が買う」か「管理者がまとめて買う」か
- 申請の受け方（アプリ内フォーム → 誰がどう承認するか）
- 「100人」の数え方（有料の購読者数で数える想定）

## 追記（2026-10-09）: 手取りの再試算と目標人数

10-01 の「手取り830円」は消費税を引いていなかった。App Store の日本の売上は 2025-04 からプラットフォーム課税で Apple が消費税を納めるので、手取りは**税抜価格×（1−手数料）**（推定。App Store Connect の価格表で要確認）。

| | 980円 | 1,480円 |
|---|---|---|
| 税抜 | 891円 | 1,345円 |
| 手取り（小規模事業者プログラム・15%） | 約757円 | 約1,144円 |
| 手取り（未加入・30%） | 約624円 | 約942円 |
| 有料1人の最悪原価（10-01推定・未実測） | 620円 | 620円 |
| 最悪時の利益（15%） | **約137円** | 約524円 |

- **小規模事業者プログラムへの加入は必須**。未加入だと先着980円の人は最悪時にほぼ利益0
- 無料1人の最悪原価は月約30円。切り替え3%なら有料1人あたり無料33人＝約1,000円で、**最悪ケースでは無料を抱えた全体が赤字になりうる**（実際は大半が上限まで使わない見込み。公開1か月の請求額で実測する）
- お試し1週間と、回数の枠の外にある3機能（日報・次の散布時期・音声の整理）の原価はこの試算に入っていない
- 月30万円（Apple手数料・消費税の後）に要る有料人数: 100人×757円＋約196人×1,144円 ≒ **約300人**（`owner-decisions.md` B3 を更新）
