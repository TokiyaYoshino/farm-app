# AI機能の訴求文言を成果ベースに書き換える

- 日付: 2026-08-23
- 状態: 採用
- 種別: 仕様変更（UI文言）

## 課題（Why）

競合調査（2026-08）で、汎用生成AI（ChatGPT / Gemini）が実質的な競合であることが分かった。「今週の天気でぶどうのべと病どうする？」は無料で聞ける。**したがって「AIが使える」こと自体に課金価値はない。**

にもかかわらず、UI のラベルは機能名がそのまま「AI日報」「AI検索」「AI画像診断」となっており、**手段（AI）を売り物として前面に出していた**。競合のアグリハブ（プレミアム）も「AI搭載」ではなく「前年のデータを詳細に分析・比較できる」と成果で書いている。

## 決めたこと

UI 文言から「AI」を前面に出す表現を落とし、**利用者にとっての成果**で書き換える。

| 場所 | 変更前 | 変更後 |
|---|---|---|
| 記録一覧ボタン | AI日報 | 日報にまとめる |
| 記録一覧ボタン | AI検索 | 記録に聞く |
| 記録一覧ボタン | AI画像診断 | 写真で診断 |
| ホーム天気カード | 防除タイミング助言 | 次の散布はいつ？ |
| 日報シート見出し | AI日報を生成 | その日の作業を日報にまとめる |
| 検索シート見出し | AI検索 | 記録に聞く |
| 防除助言シート見出し | 防除タイミング助言 | 次の散布はいつ？ |
| 画像診断シート見出し | AI画像診断 | 写真で病害虫を絞り込む |
| 記録詳細の診断ボタン | AI画像診断 | 写真で病害虫を絞り込む |

Web版（`src/App.tsx`）と Expo版（`screens/ReportScreen.tsx` / `AiSheets.tsx` / `HomeScreen.tsx`）の両方に同じ変更を適用した。

### 引き継ぎ資料の文言をそのまま使わなかった箇所

引き継ぎ資料 T2 の対応表は成果の言い回しとしては適切だが、そのままボタンに入れるには長すぎる。

- 「あなたの防除履歴と今週の天気から、次の一手」→ ボタンは「次の散布はいつ？」に短縮し、**長い方はシート内の説明文に置いた**
- 「「去年いつ散布した？」に即答」→ ボタンは「記録に聞く」

理由は、記録一覧のボタン行が**モバイル幅（375px）で既に横スクロールを起こしており**、ラベルを長くすると「帳票出力」が更に画面外に押し出されるため。成果ベースという方針は満たしつつ、長い訴求文はシート内（横幅に余裕がある場所）に配置した。

### 「帳票出力」は変更なし

T2 の対応表には「AI帳票出力 → GAP監査用の帳票が5分で出る」とあるが、実装上のラベルは元から「帳票出力」で AI を冠していない。かつ帳票出力は AI 機能ではない（`api/*` を通らない）。短さも維持したいため据え置いた。

## 検討した代替案

- **案B: 「AI」を全部残して説明文だけ足す** → 見送り。手段を売り物にする構造が変わらない
- **案C: ラベルを引き継ぎ資料の対応表どおり長くする** → 見送り。既存の横スクロール崩れを悪化させる（上記）
- **現状維持** → 見送り。汎用AIと差がつかない訴求のままになる

## 影響範囲

- **DB / 権限**: なし
- **既存機能**: 表示文言のみ。機能・導線・API呼び出しは一切変更していない。`ai_outputs.kind` などの内部識別子も未変更（`KIND_LABEL` の「画像診断／防除助言／日報／音声整理」は分析タブの履歴ラベルで、これは種別名として妥当なため据え置き）
- **ストア審査 / 規制・業界固有の実務**: なし。農薬・防除に関する注意書き（製品ラベル確認の促し、確定診断ではない旨）は文言変更の対象外で、すべて維持

## プレモータム（半年後に失敗していたとしたら、何が起きたか）

1. **「AI」を消したことで、AI機能があること自体が発見されなくなった。** 利用者が「このアプリはAIで何かできる」と認識する手がかりが消え、結果として使われない。→ 現状の利用実績（`ai_outputs` 全11件・すべて開発時の動作確認）では悪化を検知する母数が無い。**文言変更の効果・逆効果はどちらも測れない状態にある**
2. **成果ベースの表現が実態に追いつかなかった。** 「次の散布はいつ？」と問いかけておいて、記録が薄く天気の一般論しか返せない場合、期待外れになる。→ 記録の蓄積が前提（`20260823-pest-advice-history.md` のプレモータム1と同根）

## 過去の判断との関係

- `docs/roadmap.md` の「AI機能ロードマップ」は開発上の機能名として「AI日報」等を使っているが、これは内部の呼称であり UI 文言とは別物。ロードマップ側の記述は変更していない
- 矛盾・上書きする判断はなし
