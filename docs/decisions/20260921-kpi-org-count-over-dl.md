# 「1年で2万DL」を目標指標から外し、実利用組織数を使う

- 日付: 2026-09-21
- 状態: 採用
- 種別: 指標設計（KPI）
- 関連: `docs/research/dl-target-20k-2026-09.md`（本ログの根拠）、
  `docs/decisions/20260912-release-line.md`（n≧30 の凍結解除条件と同じ構造）

## 課題（Why）

`dl-target-20k-2026-09.md` の前提は「本人いわく“不可能に近い目標をあえて立てた”」で、
**この repo のどこにも「1年で2万DL」を正式な目標として書いた箇所が無い**（roadmap.md にも
事業戦略サマリーにも記載なし。唯一の記述は調査ドキュメント自身が引用した口頭の前提）。

同調査6章はさらに、**DL数そのものが測るべき指標として不適切**と結論づけている。

- 唯一 DL と実ユーザーの両方を公表している競合（畑らく日記）で実ユーザー／DL ≒ 25%
- 業界の主要プレイヤーは全員、DL数ではなく**登録者数・利用組織数**で語っている
  （アグリノート「3万組織」、アグリハブ「登録者5万人」、KSAS「会員26,400人」）
- 「使われている状態」を測りたいなら、目標は DL数ではなく実利用組織数に置くべき

**加えて、1年のカウントダウンが始まる起点も存在しない。** マルチテナント化は進行中、
App Store 申請も未公開で、外部の農場は0組織。「1年で」という時間軸自体が、
何の時点から数えるのか定義されていなかった。

## 決めたこと

### 対外的な成長目標は「実利用組織数」で語る。DL数は追わない

Web版・iOS版とも、ダウンロード数・インストール数をKPIとして追跡・公表しない。
追う場合は **「組織登録数」と「その中で実際に記録が入っている組織数」の2段**（登録だけでは
「使われている」の証明にならないため）。

### 「1年で◯組織」の数値目標は、今は設定しない

理由は2つ。

1. **カウントダウンの起点が無い。** マルチテナント化未完・外部配布0件の現時点で期限を切ると、
   `20260912-release-line.md` が診断した「出さないと分からないことに投資し続ける」構造を、
   指標の側で再現するだけになる
2. **`product-context.md` の優先順位基準に照らすと、今はまだ段階1（入力データ蓄積）。**
   段階2（外部展開）の獲得目標を段階1で確定させる必要が無い

起点は**「他農場への実配布を開始した日」**に置く。マルチテナント化の越境アクセス実地テスト
（roadmap.md「進行中」）が完了し、2組織目が乗った時点で、初めて「そこから1年で何組織」を
決める。**今回はその日付を決めない**——決めても検証も追跡もできない数字になるだけ。

### 短期の指標は変えない。retention 指標が上位

`references/workflow.md` の北極星候補（週あたり作業報告数）は、この決定と矛盾しない。
組織数は「段階2（外部展開）が動き出してから見る」指標で、**段階1の間は退場しない**。
むしろ現状（worker 0人・記録18件）で組織数の話をしても測るものが無い、という点は
`20260912-release-line.md` の n≧30 の話と同じ形。

## 検討した代替案

- **「1年で◯組織」の具体的な数値目標を今この場で決める** → 起点が無いまま数値だけ決めると、
  `dl-target-20k` の調査対象になった「2万DL」と同じ、検証不能な目標を作り直すだけ。**見送り**
- **DL数も並行して見る（廃止せず二本立て）** → 調査6章が「DL≠利用」「歩留まりはKPIに乗らない」
  と明示している。見る数字を増やすと `workflow.md` 6章の「見る数字は2〜3個に絞る」に反する。
  **見送り**

## 影響範囲

- DB / RLS: なし
- 既存機能: なし。指標運用の合意のみ
- AppStore / 法規・農業実務: なし。ストア掲載文言（`app-store-listing.md`）にも
  ダウンロード数の言及は元から無い

## プレモータム

1. **「起点を決めない」がずるずる続き、指標の話自体が消える。** → マルチテナント化の
   進捗（越境アクセス実地テスト）を見るたびに、この決定を思い出して起点の到達を確認する
2. **組織登録数だけを見て、「登録だけで使われていない」状態を見逃す。** → 2段構成
   （登録数／記録が入っている組織数）にしたのはこのため。片方だけを報告しない

## 過去の判断との関係

  あちらは**課金対象組織の目標値**で、本ログは**無料含む実利用組織数という指標の種類**の話
- `20260912-release-line.md` の「n が足りなければ議論しない」という姿勢を、
  獲得目標の側にも適用したもの
