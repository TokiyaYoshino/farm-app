# 意思決定ログ（decisions）

仕様に触る変更（新機能・仕様変更・削除縮小・リリース判断）は、大小問わず実装前にここへ 1 件 1 ファイルで記録する。文言修正・スタイル調整・バグ修正・リファクタは対象外。

- ファイル名: `YYYYMMDD-<slug>.md`（例: `20260719-voice-input-redesign.md`）
- テンプレート: `.claude/skills/pm/references/templates.md` の「意思決定ログ」
- 書くのは数分以内。埋められない項目は「不明」でよい
- 過去の判断を覆すときは、新しいログに旧ログへのリンクと覆す理由を書く（旧ログは編集しない）

運用の背景と PM プロセス全体は `.claude/skills/pm/SKILL.md` を参照。
