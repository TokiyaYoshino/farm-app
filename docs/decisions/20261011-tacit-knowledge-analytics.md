# 分析タブを「感覚知を渡す」側へ寄せる（検討）

- 日付: 2026-10-11
- 状態: **検討中（実装しない）**。App Store 0.1.0 の申請中で UI 配置は凍結中（`20260912-release-line.md`）
- きっかけ: 農家から直接聞いた心配（オーナー 2026-10-11）

## Why（農家の声）

- 農家の技術は感覚知が多く、言葉で相手に伝わらない。身につけるには成功事例を見るか、自分で経験を積むしかない
- 研修を2年やっても、その後の独立に何もつながらないことがある
- これが「農家として食えない」ことにつながり、**心配だと農家本人が言っていた**（伝え聞きではない）

事業定義（`docs/business-definition.md`）の「新人の『分からない』」の延長にある。
違いは時間の幅で、事業定義が今日の判断（次に何をするか）を見ているのに対し、この声は**研修から独立までの数年**を見ている。

## 今の分析タブで足りているか

足りていない。今の分析タブは**結果**（前年同時期比の KPI・月別収穫量・作業時間の内訳・相関）を見せる画面で、
**判断の理由**を渡す画面ではない。感覚知に近いのは相談と「今日の一手」だが、扱うのは「いつ・何を・どの農薬で」まで。

## 失敗の原因の分解

| # | 原因 | 今の farm-app |
|---|---|---|
| ① | 判断の理由が渡らない（なぜ今日やると決めたか） | △ 何をしたかは残る。なぜは残らない |
| ② | 研修先の記録を独立後に持ち出せない（記録がゼロに戻る） | ✕ 記録は組織の中に閉じている |
| ③ | 年間の段取りが身につかない（2年＝季節ごとに2回しか見られない） | △ 記録はあるが「この農場の作業暦」として見られない |
| ④ | 食えない（売上・コスト・販路） | ✕ 事業定義で売上・コスト管理は「作らない」 |

一般に、新規就農者が独立後に困るのは技術・資金・販路・農地と言われる（具体的な数字は未確認）。

## 案（推奨）

**分析タブの「相関を探す」を「この農場の作業暦」に置き換える。**

- 過去の記録から月ごとに「この時期に何をしていたか」（作業・農薬・回数）を並べる → ③
- 記録に「なぜ」を一言残す任意の欄を1つ足し、作業暦に並べて出す（例: 葉が黄色くなってきたので追肥） → ①
- 新しい入力は任意の1欄だけ。残りは既存の記録の並べ替えなので、画面と相談の数字が食い違わない
  （集計は `src/lib/metrics.ts` / `pesticideUsage.ts` の既存関数を通す）
- 相関を外す理由: 競合レビューで散布図への要望0件（2026-08 の分析画面の再構成）、記録が少ないうちは意味が出ない。
  削除はせず「さらに掘る」の奥へ下げる（CLAUDE.md の規約）

**② 記録の持ち出し**は効果が最も大きいが重い（研修先の同意・組織をまたぐ RLS・1人ごとの料金との関係）。
作業暦を書き出せる形にしておくことを、持ち出しの最初の一歩とする。本体は別の判断にする。

## ④（売上・コスト）について

事業定義（2026-09-28）で「作らない」と決めた。「食えない」が心配の核心なので、開き直すかは**オーナーの判断待ち**。
PM としては、アプリで販路・資金の問題を解ける見込みは低く、技術側（①③）を先に手当てするのを推す。

## 確かめること

| # | 仮説 | 確かめ方 | 否定される条件 |
|---|---|---|---|
| H4 | 独立後に困るのは技術（いつ・なぜ）であって、お金・販路だけではない | 自農場の新人・研修生に「独立するなら何が一番不安か」を聞く。事業定義 H2 の聞き取りと同時にやる | ほぼ全員がお金・販路と答える → ①③ を作っても心配は消えない。④ を開き直す材料になる |
| H5 | 判断の理由は、一言なら記録のついでに書いてもらえる | 0.2.0 で任意の欄を出し、`reports` のうち記入された割合を見る | ほぼ空欄 → 入力では取れない。相談のやり取りから拾う方向に変える |
