# 課金軸を「機能」から「蓄積データの活用範囲」へ移す

- 日付: 2026-09-20
- 状態: **採用**
- 種別: 仕様変更（料金体系）
- 前提: `docs/decisions/20260823-pricing-plan-review.md` の保留を解除するもの。根拠は `docs/research/dr-2026-09/`（DR-01〜DR-12）
- **本ログは方針の決定であり、コードには一切手を入れていない。** 実装は「次のアクション」の順で別途行う

## 課題（Why）

2026-08 の競合調査で Team（月2,980円）の課金理由がアグリハブのフリープランと重複していることが判明し、料金設計が保留のまま止まっていた。保留のままでは **App Store に出せない**——Apple は購読のサインアップ画面に「期間中に提供される内容」「更新時の全額」の明示を **must** として求めており（DR-06 §1.3(b)）、Pro で何ができるかが決まっていないとこの画面が書けない。App Store 申請は進行中の最優先項目（`20260912-release-line.md`）なので、ここが申請のブロッカーになっている。

## 決めたこと

**課金の線を「入れる・見る」と「遡る・出す」の間に引く。**

| | 無料 | Pro ¥980/月 |
|---|---|---|
| 記録の登録・閲覧 | **無制限** | 無制限 |
| 分析・検索・カレンダーの参照範囲 | **直近12ヶ月（当シーズン）** | **無期限**（前年同期比・複数年比較・全期間の記録検索） |
| 帳票出力（農薬使用履歴CSV等） | ✗ | ◯ |
| AI の日次上限 | 現行のまま（`api/_auth.ts` の `DAILY_LIMIT`） | 緩和 |
| 農薬の使用基準チェック・超過警告 | **◯（無料のまま）** | ◯ |
| 利用人数 | **無制限** | 無制限 |

あわせて次の4点を決める。

1. **人数課金（席数）を廃止する。** Team の「10人まで¥2,980＋超過¥400/人」をやめる。組織向けの課金は将来、席数ではなく**組織運用機能**（権限管理・作業者別実績・監査ログ）に寄せる。
2. **収益源を法人 Team から個人 Pro へ移す。** アグリハブは規約相当の注記で個人に有料プランを売っておらず（DR-02 §1）、**個人農家向け有料という席が空いている**。
3. **価格は ¥980/月 据え置き。** アグリノートS（月あたり約917円）と KSAS 有料（2,200円/月）の間で、下げる理由がない。
4. **決済は iOS の App内課金を第一線、Web（Stripe）を並行して持つ。** IAP はキャリア決済（ドコモ払い・auかんたん決済・ソフトバンクまとめて支払い）を標準で含み、カードを登録していない高齢層の脱落を減らせる（DR-07 §5）。Stripe は 12月の着金を落とさないための保険（DR-06 §8）。

### なぜこの線か

- **競合3社はいずれも機能でも人数でも課金していない。** 課金軸はアグリハブ＝参照期間（分析・検索が直近10ヶ月）、アグリノート＝記録件数と圃場数、KSAS＝圃場枚数（DR-02）。「蓄積データの活用範囲」は業界の常識側にある。
- **無料枠で埋まっている機能に課金しようとしない。** 病害虫診断・GAP管理・特別栽培・記録無制限・複数人利用は、すべてアグリハブのフリープランに入っている（DR-02 §2）。ここに課金理由を置くと1件も売れない。
- **帳票出力は競合も有料にしている。** アグリハブの「圃場情報出力」はフリーで✗（DR-02 §1）。しかも帳票の用途（確定申告・GAP認証・出荷先提出）は、記録アプリで最も強い継続要因でもある（DR-12 §3.2）。
- **参照範囲ゲートは農業と相性がよい。** 「前年の同じ時期にどうしたか」が意思決定に直結するため、無料/有料の境界がそのまま業務価値の境界になる。farm-app は既に前年同時期比のKPIを持っている（`src/lib/metrics.ts`）。
- **安全に関わる判定は課金の後ろに置かない。** 農薬の総使用回数は法的義務であり、超過の疑いの警告は無料のまま維持する（`20260805-pesticide-precheck.md` の非対称判定をそのまま残す）。

## 検討した代替案

- **案B: 記録件数で絞る（アグリノート型、無料20記録）** → 見送り。アグリハブの無料が記録無制限なので、比較表で最も目立つ負け筋になる（DR-02 §2）。**記録の無制限性は差別化ではなく前提**として扱う。
- **案C: AI機能の無制限を課金軸にする（roadmap 2026-07 の設計）** → 見送り。汎用生成AIが実質的な競合であり「AIが使える」こと自体に課金価値がない（`20260823-ai-wording-outcome-based.md`）。加えて病害虫診断はアグリハブ無料に入っている。AIの日次上限は原価管理として残すが、**課金軸の看板にはしない**。
- **案D: 人数課金（畑らく日記型、200円/ID・最低5ID）** → 見送り。大手3社が人数を無料・無制限にしており、比較時に最も目立つ弱点になる（DR-02 §3）。さらに個人経営体は1経営体あたり平均1.3人で（DR-03）、席数を積む母数自体がない。
- **案E: カード先行登録を求めて転換率を上げる** → 今回は見送り。サインアップ分母では30%（カード不要の5倍以上）だが、訪問者分母に直すと差は2倍に縮み、入口が 90/1,000 → 35/1,000 に絞られる（DR-10 §2）。**高齢個人農家がカード情報を先に入れるかの実測データは皆無**で、この層では入口の縮小が支配する危険が大きい。採用するなら小規模A/Bで登録率とカード入力離脱率を測ってから。
- **現状維持（保留を続ける）** → 見送り。App Store 申請のブロッカーになっている（上記 Why）。

## 影響範囲

- **DB / RLS**: `organizations.plan` が既にあるので新規テーブルは不要。**参照範囲と帳票のプラン判定はサーバ側に置く**（クライアント判定だけでは意味がない）。RLS でテナント分離済みのクエリに、さらに期間条件を重ねる形になる。
- **既存機能（重要）**: 帳票出力（農薬使用履歴CSV、`src/App.tsx` の「農薬使用履歴 帳票出力」）と前年同時期比KPIは、**すでに無料で動いている**。これを Pro に移すのは機能の削除ではない（CLAUDE.md の規約に抵触しない）が、既存利用者の体験は後退する。→ **現在の organization は plan を据え置き、制限を適用しない（grandfathering）。** 現状の利用者はβ2人・本番worker0人なので、今なら移行コストがほぼゼロで済む。
- **AI**: `api/_auth.ts` の `DAILY_LIMIT` をプラン別に読み替える。Web版リリースで入れた fail-open の方針（`20260909-web-release-and-rollback.md`）は維持する。
- **AppStore / 法規・農業実務**: 3.1.2 の必須表示（名称・期間・提供内容・更新時の全額・復元導線・規約/プライバシーポリシーのリンク）を購入画面に実装する。**「1日あたり約32円」のような内訳価格を実課金額より目立たせない**（DR-06 §1.3）。帳票の用途は確定申告・GAP・出荷先提出で、農薬の使用基準（法的義務）の判定は無料側に残す。

## プレモータム（半年後に失敗していたとしたら、何が起きたか）

1. **帳票と前年比を有料に移した結果、無料の価値が薄まり、そもそも使い続けてもらえなかった。** 戦略順序の段階1（入力データ蓄積）を自分で壊し、課金する前に記録が止まった。
2. **参照範囲ゲートが初年度に効かなかった。** 蓄積が12ヶ月を超えるまで「遡る」価値が発生しないため（DR-10 §4 B案の構造的弱点）、1年目のユーザーの課金理由は帳票だけになり、確定申告期（2〜3月）まで転換がゼロだった。
3. **課金軸だけ決めて制限の実装とプラン判定を後回しにし、App Store 申請時に「Pro で何ができるか」を結局書けなかった。** 決めた意味がなかった。

## この決定が前提にしていない論点（未決・別判断）

**「2026年12月末に月額30万円（307件）」という目標期日は、この決定では変えていない。** ただし調査はこの期日に一貫して不利な材料を出しており、次の数字は記録しておく。

| 段 | 値 | 出典 |
|---|---|---|
| 12月末に307件を**残す**のに必要な累積獲得 | 342〜393件（月次チャーン3〜7%） | DR-12 §4.2 |
| そのために必要な無料登録者（転換率3〜5%、登録者分母） | **約7,300〜12,200人** | DR-10 §1 |
| 予算ゼロの無料チャネルで10週に確定計上できる到達 | **1桁〜数十インストール** | DR-04 §3 |
| ニッチB2Bで10週1万ユーザーの前例 | **なし** | DR-09 §4 |
| 12月の作業量 | 稲作・露地・果樹は農閑期（施設園芸のみ最盛期） | DR-08 §7 |

**必要な入口と、用意できる入口の間に3桁の開きがある。** 12月末に金額目標を置き続けるなら、無料チャネル以外の計画（媒介者＝JA営農指導員・普及センター経由、または有料獲得）が別途要る。期日そのものを動かす判断は本ログの範囲外。
