# 料金: 無料＋月980円（農場ごと・相談の回数で差をつける）

- 日付: 2026-10-01
- 状態: 採用
- 種別: 仕様変更（料金体系）
- 関連: `20260823-pricing-plan-review.md`（保留だった論点に答える）、`20260928-business-definition.md`、`docs/owner-decisions.md`

## 課題（Why）

オーナーの方針: **有料プランは最初の版（0.1.0）から入れる。設計上、最初から赤字の無い構造にする。**
2026-07 の料金表（Free / Pro 980円 / Team 2,980円）は、Team の課金理由が競合の無料版と重なり保留になっていた。

## 決めたこと

| | 無料 | 有料 |
|---|---|---|
| 価格 | 0円 | **月980円・農場ごと**（管理者が買えば農場の全員に効く） |
| 課金の方法 | — | ストア内課金（IAP）。Apple 小規模事業者プログラムで手数料15%＝手取り約830円 |
| 作業の記録・農薬の使用回数の表示・前年比 | 無制限 | 無制限 |
| 相談（記録に聞くを含む。1件の中のやりとりは数えない） | **農場で週3件** | **農場で1日8件** |
| 写真で調べる | 農場で週1回 | 農場で1日3回 |

- プランは無料と有料の2つだけ。**Team プランは作らない**（人数の多い農場向けは、実際に来てから決める）
- 差は**相談・確認の回数**でつける（機能では差をつけない）
- 回数は**人ごとではなく農場ごと**に数える（売上が農場ごとなので、原価の上限も農場ごとに決める）

## なぜ黒字になるか（原価は推定・未実測）

前提: `gpt-4o-mini`（入力 $0.15・出力 $0.60／100万トークン）、1ドル150円、相談1件＝約1〜2円、写真1回＝約0.5〜1.5円（推定の上限側で計算）。

- 有料農場の最悪（毎日上限まで使う）の原価: 30日 ×（8件×2円＋3回×1.5円）≒ **月約620円** → 手取り830円に対し**利益210円以上**
- 無料農場の最悪の原価: 月約13件×2円＋4回×1.5円 ≒ **月約30円**
- 有料1農場の利益で、無料の農場を最悪でも約7、現実的な利用なら20以上支えられる。無料→有料の切り替え率は一般に2〜5%（有料1に対し無料20〜50）

**検討して退けた案**: 無料を1人1日3件。無料1人の最悪の原価が月約220円になり、無料20〜50農場を有料1農場で支えられない。

## 見直す条件

- 最初の1か月の OpenAI の実際の請求額から、1件あたりの原価を実測する。推定を下回れば回数を増やす（**緩める方向のみ**。絞る変更は反発が大きい）
- 原価を下げる手（前置きの共通化によるキャッシュ等）が効いたら、無料の回数を増やす

## 影響範囲（0.1.0 に開発が発生する）

有料を最初から入れるため、`20260912-release-line.md` の「App Store に必要な機能開発はゼロ」は**成り立たなくなった**。必要なもの:

- アプリ内課金（定期購読）の実装: 購入・購入の復元・購読状態の表示。Apple のガイドライン 3.1.1 / 3.1.2（購読の内容・期間・価格・解約方法の表示、利用規約とプライバシーポリシーへのリンク）
- 購読状態を**組織（農場）に紐づける**サーバー側の記録（DB に列かテーブルが1つ増える。RLS の確認が要る）
- 回数の数え方を、今の「1日50回・画像20回の支出の歯止め」から、農場ごと・週／日の枠に置き換える（`ai_outputs` を数える）
- 上限に達したときの表示（有料への案内）。文言規則（CLAUDE.md）に従う
- Apple 小規模事業者プログラムへの申し込み（オーナー）
- 利用規約（定期購読の条項）の用意

設計の詳細は別の ADR で決める（DB・購読の検証方式・Web 版の扱い）。
