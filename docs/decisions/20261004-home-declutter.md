# ホームのカードを7枚から3枚に減らし、記録タブを「開いたらすぐ書ける」形にする

- 日付: 2026-10-04
- 状態: 採用（Expo版のみ実装。Web版 `src/App.tsx` は据え置き）
- 種別: 仕様変更（情報設計・画面レイアウト）

## 課題（Why）

`20260823-ai-information-architecture.md` の実測でホームは**カード7枚・1.3画面**。その後の判断（`20260906-general-advice-entry.md`）で「新カードは作らない」と決め、`docs/handoff-ai-entry-ux.md` 4-1 でも「**減らす方向**の検討になる」と残していた。

Expo版ホームの構成（作業中・新着コメントは条件付きのため除く）:

| 変更前 | 変更後 |
|---|---|
| 天気 | 今日の一手の1行目へ統合 |
| 今日の一手 | 今日の一手（天気を内包） |
| 統計グリッド（直近7日の作業・今週の収穫） | 外した（収穫は分析タブ） |
| 今日の予定 | 今日の予定 |
| 作付け中 — 相談できます | 1枚のカードに行で集約 |
| 記録一覧への導線 | 〃 |
| 圃場マップ | 〃 |

**7枚 → 3枚**。iPhone 17 Pro のシミュレータで、3枚とも1画面に収まることを確認した（2026-10-06）。

オーナーの指摘（2026-10-04）:
- 「タブを開いたら自分のやりたいことがすぐできる」
- 相談行の補足（灰色の小さな2行）は「美しくない」
- 「予定が入っていないとわかりにくい」
- 常に出す説明は1行まで。カレンダーは自分から見にいくもの

## 決めたこと

### ホーム（`expo-prototype/screens/HomeScreen.tsx`）
1. **天気は単独カードにしない。** 散布判断に効く情報なので、今日の一手の1行目に hairline で区切って入れる。相談機能が使えない環境（今日の一手が出ない）でだけ、天気を1行のカードで出す
2. **統計（直近7日の作業・今週の収穫）はホームから外す。** 毎日ホームで見る数字ではない。収穫は分析タブで見られる。「直近7日の作業件数」はどこにも置いていない（要るなら記録タブに足す）
3. **相談・記録一覧・圃場マップは1枚のカードに行で並べる**（`CLAUDE.md` のリスト規則「1枚のカードに hairline 区切りの行」）。相談行の補足文は外し、押した先（相談シート）で1行だけ言う
4. 今日の一手の農薬名は押すと開く。ふだんは「日付 · 作物 · 圃場」の1行
5. 今日の予定:
   - 空のときは何の欄かと、入れると何が起きるかを書く
   - 以前の「作業を追加」は**予定ではなく作業記録を開いていた**。記録は右下の「＋記録」に任せ、ここは「予定を入れる」（`ScheduleAddSheet.tsx`）にする
   - 予定の行から記録を始められる（日付・作業・作物・圃場・担当を入れて入力シートを開く。記録タブと同じ）
   - 作業名を太字の見出しにし、作業の色は小さな点で示す

### 記録タブ（`expo-prototype/screens/ReportScreen.tsx`）
- 「今日の流れ」（F案）: 作業を選ぶ → 記録 or 予定。ホームの「＋記録」シートと同じ部品を使う
- 予定も記録も無い日は、何の欄かと次に何が起きるかだけを書く
- カレンダーは開いた時点では出さない（自分から見にいくもの）

### 共通（`expo-prototype/App.tsx`）
- 分析・管理のサブタブ切替（`SubTabBar`）は記録タブと同じ見た目（灰の受け皿＋白いピル）にそろえ、下線タブはやめた
- 右下の「＋記録」（押すと「作業を選ぶ」シート）は、記録タブでは同じ部品が画面にあるので出さない

## 却下した案

- **カードは残して中身だけ詰める** → 枚数が変わらず、縦の長さの問題（1.3画面）が解けない
- **統計をホームに残し、天気を消す** → 天気は散布判断（今日の一手）と一緒に読むもの。統計は記録を見に行くときに使う数字

## 影響範囲

- **既存機能**: 「直近7日の作業件数」の表示はなくなった（収穫は分析タブに残る）。それ以外は入口の位置が変わっただけ（天気 → 今日の一手の中）
- **Web版**: 未着手。Web版にもそろえるかは別に判断する
- **未決**: `docs/handoff-ai-entry-ux.md` 4-1（ホームに AI の起点が3つ並ぶ件：次の散布時期／写真で調べる／相談する）は今回の範囲外。カードは減ったが起点の数は変わっていない
