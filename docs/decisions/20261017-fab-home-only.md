# 「＋記録」の浮いたボタンはホームだけに出す（2026-10-17）

## 決めたこと
Expo版の「＋記録」（右下の浮いたボタン）を**ホームだけ**に出す。相談・分析・管理・記録では出さない。

## なぜ
- 分析タブでグラフに重なり、邪魔だった（オーナー 2026-10-17、シミュレータで確認）
- 浮いたボタンは「その画面の主な用事」に置くもの（Material Design: FAB は画面の主操作を表し、全画面には要らない）。
  分析＝見る、管理＝設定する、相談＝聞く で、どれも主な用事は記録ではない
- 記録へはタブバーの「記録」から1回で行ける。相談には返答の下に「この判断で記録する」がある
- ホームには記録へ直接行くボタンが他に無いので、ここだけ残す

## リリース前ルールとの関係
3問（審査／必達3タスク／数字の食い違い）には当たらないが、「タブを開いたらその用事がすぐできる」
（オーナーが実害と判断した軸）を優先した。見せ方の調整で、新機能ではない。

## 他の選択肢
- ホームと相談に残す → 相談には「この判断で記録する」があるので重複になり、見送り
- スクロールで縮める（Gmail の「作成」）→ 縮めてもグラフ・入力欄に重なるので見送り

## 戻す条件
テスターから「分析・相談から記録しにくい」という声が出たら、相談への追加から見直す。
