# App Store Connect 入力文言（ドラフト）

`docs/app-store-submission.md` 6章「App Store Connect の入力項目」に貼り込む文言。
**このファイルからコピーして使う。** 文字数は Apple の上限内に収めてある（末尾に実測値）。

方針:

- **「AI」を前面に出さない**（`docs/decisions/20260823-ai-wording-outcome-based.md`）。
  汎用の生成AIが実質的な競合で、「AIが使える」こと自体に価値は無い。成果で書く。
  **例外はサブタイトルのみ**（理由は下記）。説明文とプロモーションテキストでは出さない
- **農薬の判定を断定しない**（`docs/decisions/20260805-pesticide-precheck.md`）。
  「使いすぎを判定します」ではなく「**使いすぎの疑いを知らせます**」。
  総使用回数が自然文で数値化できない農薬があり、判定不可側に倒しているため、
  ストアの文言でも過剰に約束しない。最終的な正はラベル表示である旨も入れる
- **アカウントは農場の管理者が発行する**と明記する。自由登録できない理由の説明になり、
  Guideline 5.1.1(v) 対策を兼ねる
- **課題→解決の形で書く**（2026-09-05・吉野さんの方針）。機能を並べるのではなく、
  実在する困りごとに解決策を当てる。目指す世界は **「楽をして品質の高いものを作る」**。
  拾う課題は4つ:

  | 課題 | 当てる解決 | 実装 |
  |---|---|---|
  | 忘れてしまう | 記録に聞けば答えが返る | 記録検索チャット |
  | 何をしたらいいんだっけ | 状況を伝えると、やること・時期・理由が返る | 相談エージェント（`api/advise.ts`） |
  | 病害虫にやられた | 写真から**原因の候補**が挙がる | 画像診断（`api/diagnose-image.ts`） |
  | 複数人の動きが見えない | 予定・実績・コメント・ガントが1つに | カレンダー / ガント / 通知 |

- **画像診断は「対策」まで書かない。** 実装が返すのは原因の候補（病名・虫名・確信度・根拠）までで、
  対策は意図的に生成していない（`api/diagnose-image.ts` のプロンプト:「注意書きは画面側で
  固定表示するため生成しないこと」）。防除の対策＝農薬の推奨であり、作物と病害虫の
  組み合わせごとに登録が違うため、誤った推奨は使用者を農薬取締法違反に導く。
  **診断→相談の導線を作れば「その後どうするか」まで言えるようになる（未実装・要検討）**

### 「AI」をサブタイトルに入れる理由（2026-09-05）

`docs/decisions/20260823-ai-wording-outcome-based.md` は UI から「AI」を落とす判断だが、
**ストアのサブタイトルは別の仕事をする**ため、ここは例外にする。

- **検索目的ではない。** Apple はアプリ名＋サブタイトル＋キーワード欄をまとめて索引するので、
  キーワード欄に既に入れてある語を重ねても効果は薄い。**重複させるだけ枠の無駄になる**
- **一覧で並んだ瞬間の判断材料として置く。** 競合（アグリハブ）が AI 病害虫診断を前面に
  出しており、この分野で AI は差別化ではなく**最低条件**になっている。無いと古く見える
- 重複を避けるため、**キーワード欄からは `AI` を外し、空いた枠を `病害虫,診断` に回した**

UI 側の文言は従来どおり成果ベースのまま（この例外はストア掲載文にのみ適用する）。

## 説明文

```
楽をして、いいものを穫る。
農作業レポートは、紀州の梅農家での実際の運用から生まれた農場管理アプリです。
記録するほど、あとで考える手間が減っていきます。

■「あれ、いつ撒いたっけ」
去年の防除の時期も、今年の収穫量も、聞けば自分の記録から答えが返ります。
言い回しが違っても探せるので、記録をめくり直す必要はありません。

■「今、何をすればいい？」
作付けの状況を伝えると、次にやること・その時期・そう考える理由が返ります。
気になっている点や、判断のために足りない情報もあわせて示します。
出てきたやることは、実際の作業記録と自動で突き合わせて、済んだかどうかが分かります。

■「この葉、何にやられた？」
葉や実の写真から、病害・虫害・生理障害・ウイルス病のどれにあたるか、
考えられる原因を確信度と根拠つきで挙げます。写真だけで判断できないときは、
その旨をはっきり示します。
※ 診断は候補の提示までです。防除の判断は、農薬のラベル表示とJA・専門家への
　 ご相談のうえで行ってください。

■「みんなの動きが見えない」
予定を入れておくと、作業報告が上がった時点で自動的に突き合わせ、誰の作業が
未報告なのかが一目で分かります。作業へのコメント、メンション通知、計画の
ガントチャートで、複数人の農場でもアプリひとつで状況を追えます。

■ 記録そのものは、その場で終わる
圃場に立ったまま、作業種別・圃場・収穫量を数タップで。写真の添付、音声での入力、
開始と終了の時刻からの作業時間の自動計算に対応。天気・気温は記録した時刻のものが
自動で入ります。

■ 農薬の使いすぎに気づける
散布した農薬を記録すると、農薬登録情報（独立行政法人 農林水産消費安全技術センターが
公開するデータ）と自分の散布履歴を突き合わせ、総使用回数を超えている疑いがあるときに
知らせます。
※ 判定はあくまで目安です。最終的な使用可否は必ず製品ラベルの表示をご確認ください。

■ 前年と並べて振り返る
収穫量・目標達成率・作業時間・防除回数を、前年の同じ時期と並べて表示します。
振り返りは年に一度でも、そのときに必要な数字がすぐ出ます。

ご利用にあたって

　アプリ内での新規登録はできません。
・写真・位置情報の利用は、記録への添付と圃場の位置設定のためだけに使用します。
・記録したデータは所属する農場の中でのみ共有されます。
```

## 吉野さんに決めていただきたいこと

1. **サブタイトル** — 上の本命でよいか、代案2つのどちらかにするか

4. **価格** — 無料（`docs/app-store-roadmap.md` の「先に決めておくこと」のとおり）
5. **デモアカウントのID/パスワード** — Web の管理画面で作成が必要
