# 農業ドメイン知識スキル

このスキルは「システムをどう作るか」ではなく「農業という現場を正しく理解しているか」を担保する。プロダクトの意思決定（pm スキル）に農業の実務・法規の裏付けを与えるのが主目的だが、単体の知識確認にも使ってよい。

## 使い方

1. **pm スキルの一部として呼ばれた場合**（仕様変更の影響範囲評価など） — 該当する reference を読み、法規適合・実務との整合・データの意味の観点でコメントする。断定できない前提（対象作物・地域の栽培方式など）は「要確認」と明示し、DB の作物マスタや過去記録で確認できるならそちらを優先する。
2. **単体の知識質問として呼ばれた場合**（「防除の時期は？」「GAPって何？」等） — 該当 reference を読んで直接答える。farm-app の実装判断は求められていない場合、無理に紐付けない。
3. **知らないことを知らないと言う。** 農業は地域・品目・年によって実務が大きく変わる分野。ここにある情報は一般的な目安であり、実際の防除暦・使用基準は農薬ラベルや地域の指導機関（JA・普及指導センター）が最終的な正。断定が必要な法規・使用基準の話は「ラベルの表示が最優先」と必ず添える。

## 参照ファイル

- `references/legal.md` — 農薬取締法・使用基準・帳簿記載義務、食品衛生法のポジティブリスト制度。**義務か努力義務かを混同しないこと**が最重要（誤って「記録は法的義務」と案内すると過剰な入力負担を正当化してしまう）
- `references/cultivation.md` — 防除体系（IPM）、施肥設計の考え方、果樹（特に南高梅・温州みかんなど紀州の主要品目）の年間栽培サイクルの具体例
- `references/certification-and-data.md` — GAP認証（JGAP/ASIAGAP/GLOBALG.A.P.）、エコファーマー・有機JAS・特別栽培の違い、農業データ連携基盤（WAGRI等）とトレーサビリティ
- `references/field-ux.md` — 圃場・作付けの基本概念、農家ユーザーの利用実態（屋外・繁忙期・IT習熟度の幅）、記録データの資産価値
- `references/labor-and-safety.md` — 農業労働力の波（繁忙期集中）、家族経営・季節雇用・特定技能などの労働力確保手段、農薬散布時の保護具・中毒予防、GAPの安全教育記録要件

## farm-app への橋渡し

farm-app 固有のプロダクト判断基準・優先順位は `.claude/skills/pm/references/product-context.md` にある。このスキルはあくまで農業の知識を提供する側で、「だから何を作るべきか」という判断は pm スキル側の役割——両者は分業であって、このスキルが直接「実装すべき」と結論を出すことは避け、判断材料を渡すことに徹する。
