# 認証制度とデータ活用

farm-app の「記録の蓄積」がどんな外部価値に接続しうるかを理解するための知識。GAP・栽培方式表示・農業データ連携基盤の3系統を扱う。

## 1. GAP認証（JGAP / ASIAGAP / GLOBALG.A.P.）

GAP（Good Agricultural Practice：農業生産工程管理）は、食品安全・環境保全・労働安全・人権福祉などの観点で生産工程を管理する取り組み。第三者認証には主に3種類あり、性質が異なる：

| 規格 | 特徴 |
|---|---|
| **JGAP** | 日本発、国内・アジア向け。GFSI（世界食品安全イニシアティブ）の承認は未取得 |
| **ASIAGAP** | JGAPをベースに GFSI 承認を取得した規格。国内外の大手小売・輸出取引で通用しやすい |
| **GLOBALG.A.P.** | 世界基準。欧州への輸出では原則この認証が求められる |

いずれも中核は**記録**：農薬使用記録（`legal.md` の5項目＋作業者・使用機材等）、肥料使用記録、収穫記録、作業者の安全教育記録など。farm-app が既に持つ「誰が・いつ・どこで・何を」の記録はこれらの認証要求と方向性が一致しており、**将来の「GAP対応記録エクスポート」は外部展開・輸出志向の産地との取引で差別化になり得る**。

認証取得自体は審査・費用を伴う重い意思決定であり、farm-app 側で「認証を取る」判断まではしない。プロダクトとしてできるのは、認証審査で提出しやすい形（項目の網羅性・エクスポート可能性）を保つこと。

## 2. 栽培方式の表示制度（エコファーマー・有機JAS・特別栽培）

- **有機JAS**：農薬・化学肥料を原則使用しない、遺伝子組み換えでない、作付け前2年（多年生作物は3年）以上有機的に管理された圃場で生産、などを満たす国家規格。認証機関の検査が必要で、認証なしに「有機」「オーガニック」と表示すると法令違反になる。
- **特別栽培農産物**：その地域の慣行栽培と比べ、節減対象農薬の使用回数が50%以下、化学肥料の窒素成分量が50%以下で栽培されたもの。有機JASほど厳格ではないが、地域の慣行基準との比較が前提になる。
- **エコファーマー**：持続性の高い農業生産方式の導入計画を都道府県知事に提出し認定される制度。有機JASや特別栽培より基準は緩く、罰則を伴う認証制度ではないが、環境保全型農業直接支払交付金などの支援を受けられる。

これら3制度は**基準の厳しさが異なるだけで、いずれも「通常よりどれだけ農薬・化学肥料を減らしたか」の記録と比較が前提**。farm-app が農薬使用量を記録していること自体が、将来これらの表示・認定を検討する際の基礎データになる。

## 3. 農業データ連携基盤とトレーサビリティ

- **WAGRI（農業データ連携基盤）**：農研機構が運営するオープンAPI基盤で、気象・農地・土壌・病害虫・市況などのデータを一元的に提供する。個々の農場・システムが同じデータを個別に持たなくて済むようにする「データシェアで農業を盛り上げる」という位置づけ。farm-app が将来、気象データや病害虫発生情報を外部連携で取り込む場合、WAGRI 経由の連携が選択肢になり得る。
- **トレーサビリティ**：「いつ・どこで・誰が・何を・どうしたか」を遡って追跡できる状態。防除記録・収穫記録が紐づいていれば、出荷後に問題が起きた際の原因追跡や、消費者・取引先への説明が可能になる。GAP認証や輸出時の要求はこのトレーサビリティの担保が目的。

## 4. プロダクト判断への含意

- 記録項目を減らす・意味を変える仕様変更は、GAP・表示制度・トレーサビリティのいずれかを弱める可能性がある。影響評価では「この変更後もどの認証・表示制度の要求を満たせるか」を一言確認する。
- 外部展開・データ価値化フェーズ（`product-context.md` の段階3）に進む際、GAPエクスポートや外部データ連携（WAGRI等）は初期の有力候補になる。ただし今は時期尚早（`product-context.md` の戦略順序を優先）。
- 「有機」「無農薬」等の表示に関わる機能（例：栽培方式のラベル表示）を作る場合は、法令上の表示制度（有機JAS等）との整合を必ず確認する——認証なしに「有機」と表示させる機能は法令違反を助長するリスクがある。
